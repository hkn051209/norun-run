# のるんラン（ランタイプ：ステージ1・2／かけざん／エンドレス）

## 公開のしかた
このフォルダの中身をそのまま GitHub Pages などに置き、index.html を開くだけで遊べます。外部サイトは使いません。

## ファイル
- `index.html` … 画面の骨組みと見た目（CSS）
- `src/config.js` … ステージ・変身・難易度・障害物の並べ方。**調整はほぼここだけ**
- `src/questions.js` … 出題（さんすうランの問題プールを流用。かんたんは ● 表示）
- `src/storage.js` … プレイヤーごとの保存（端末内のみ）
- `src/main.js` … 3D表示・のるんの動き・コース・画面遷移

## よく触るところ（src/config.js）
- ステージを増やす：`STAGES` に1つ足して `ready: true` にする
  - `speed` 速さ（計算する時間が必要なので むやみに上げない）/ `sections` 障害物区間ごとの列数（区間のあとに算数ゲート）
  - `choices` ゲートの選択肢：`2`＝扉2つ＋壁、`3`＝3レーンぜんぶ扉。`[2, 3, 2]` のように配列にするとゲートごとに変えられる
  - `theme` 景色（`THEMES` の field＝はらっぱ / forest＝もり）。障害物の見た目もテーマで変わる
- かけざん：`DAN_RUN`（速さ・1区間の障害物の列の数など）。じゅんばん／ランダムとも9問、クリアで小物1つ
- エンドレス：`ENDLESS_RUN`。`rewardEvery` 問せいかいごとに小物1つ。速さは `speed` から 100mごとに `speedUp` ずつ上がる（`maxSpeed` まで）。`threeFrom` ゲート目から ときどき3択
- 小物：`HAT_COLORS`（帽子の色）。ピンズはモデル改修後に追加予定
- 障害物の記号：`L` ひくい（丸太・きりかぶ：ジャンプ）、`T` たかい（岩・大きな木：よける）
- 変身：ランでは `look`（体の色・透け具合・しっぽなどの飾り）と図鑑コレクションだけ。速さなどは変わらない
  - `ability`（fast / float / roll / phase）はアスレタイプ／塔モード用に取ってある

## 操作
- 左右スワイプ・◀▶ボタン・←→キー：レーン移動
- 上スワイプ・タップ・ジャンプボタン・スペース：ジャンプ

## 見た目の比べ方
URL の末尾に `?classic` を付けると、前の見た目（高いカメラ・平らな道・原っぱ）で遊べます。付けなければ新しい見た目（低いカメラ・石だたみ・縁石・柵・生け垣・近くの大きな木）です。
カメラの位置は `src/main.js` の `CAM`、走る揺れの大きさは `SWAY` で調整できます。

## 道ばたの素材（Kenney Nature Kit）
- どのテーマで どの木・花を使うかは `src/main.js` の `KIT_THEMES`、色の置きかえは `KIT_RECOLOR`
- 新しいモデルを足す時は `assets/models/nature/` に GLB を置いて、`KIT_THEMES` に名前を足す
- 素材が読めなかった時は、図形で作った柵・生け垣・木に自動で切りかわる

## 動作確認用
URL の末尾に `?debug` を付けると、開発者ツールから `G` で中身を操作できます（ふだんは無効）。
