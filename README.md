# のるんラン（ランタイプ ステージ1）

## 公開のしかた
このフォルダの中身をそのまま GitHub Pages などに置き、index.html を開くだけで遊べます。外部サイトは使いません。

## ファイル
- `index.html` … 画面の骨組みと見た目（CSS）
- `src/config.js` … ステージ・変身・難易度・障害物の並べ方。**調整はほぼここだけ**
- `src/questions.js` … 出題（さんすうランの問題プールを流用。かんたんは ● 表示）
- `src/storage.js` … プレイヤーごとの保存（端末内のみ）
- `src/main.js` … 3D表示・のるんの動き・コース・画面遷移

## よく触るところ（src/config.js）
- ステージを増やす：`STAGES` に1つ足して `ready: true` にする
  - `speed` 速さ / `sections` 障害物区間ごとの列数（区間のあとに算数ゲート）/ `choices` 2択か3択 / `patterns` 出る障害物
- 障害物の記号：`L` 丸太（ジャンプ）、`T` 岩（よける）、`B` ぼう（パンでくぐる）、`F` さく（おばけはすりぬけ）
- 変身の特技：`FORMS` の `ability`（fast=ねこ / float=くらげ / roll=パン / phase=おばけ）

## 操作
- 左右スワイプ・◀▶ボタン・←→キー：レーン移動
- 上スワイプ・タップ・ジャンプボタン・スペース：ジャンプ
- 下スワイプ・↓キー：ころがる（パンのとき）

## 動作確認用
URL の末尾に `?debug` を付けると、開発者ツールから `G` で中身を操作できます（ふだんは無効）。
