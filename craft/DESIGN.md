# のるんクラフト（仮） 設計メモ（v3）

のるんが 主役の、ブロックで できた 広い 世界を 歩いて「たたく・おく・つくる・かく」ゲーム。

- v1：世界・視点と 移動・こわす／おく・素材9種・保存・PWA
- v2：夜／セーブ4つ／あいことば共有／叩いて こわす＋道具と クラフト／おえかき（武器・ペット・道具）／敵／色集め／つり
- **v3（この 版）**：世界を 256×256 に 拡大（バイオーム・洞窟・鉱石・あかり）／動物／持ち物画面と マス目クラフト／ハート・おなか・経験値／作業台の 絵／クリエイティブ⇔サバイバル／一人称／プレイヤー名と 名札／レア色と 帽子の 色
- マイクラ本家の 絵・名前・音・キャラクターは 使って いない。仕組みと 画面の 並び方だけ 参考に し、絵・名前・音は ぜんぶ 自作（コードで 生成）。
- 構成は v2 の まま：`index.html` ＋ `src/` ＋ `lib/`（Three.js r160＋GLTFLoader を 同梱）。importmap。外部CDN・ビルド・新しい ライブラリ なし。
- フォルダを そのまま GitHub Pages に 置けば 動く。
- **v2 の セーブは 引きつがない**（キーも 形も 別）。

## 1. 世界

- 大きさ：**256 × 256 マス、高さ 40**（`WORLD`）。ぜんぶで 2,621,440 マス。位置番号＝`x + 256 × (z + 256 × y)`。
- **地形は シード（乱数の 種）から 自動生成**。スロットごとに シードを 持つ。**同じ シード → かならず 同じ 世界**。
  生成は 起動時に 世界ぜんたいを 一度に 作る（パソコンで 0.3〜0.5秒）。メモリは 約 5MB（今の 地形＋生成直後の 地形）。
- **セーブは「変えた ブロックだけ」**（`changes`）。世界ぜんたいは 保存しない。読みこむ 時は シードから 作り直して、差分を 当てる。
- 世界の はしは 見えない かべ。いちばん 下（y=0）は こわせない「そこの いわ」。水面は y=17（`WORLD.sea`＝18）。

### 生成の 順（`world.js` の `generate(seed)`）
1. **高さと バイオーム**（柱ごと）：なめらかな 乱数を 重ねる。大きな 起伏（70マス周期）＋小さな でこぼこ（22マス）＋山（95マス。山は 3マスごとの 段々＝崖に なる）。地面の 高さは y=4〜31。
2. **地面と 水**：下から そこの いわ → いし → つち（2〜3マス）→ 表面。高さが 水面より 低い 所は 水（＝池・湖）。水ぎわは すな。
3. **洞窟**：通路（2つの 3次元の 乱数が ともに まん中に 近い 所を 空洞に）＋ 深い 所（y<13）の 広間。**深いほど 通路が 太い**。水の 下と 水の となりは ほらない（水は 流れない ため）。ところどころ 地上に 口が 開く。
4. **鉱石と 結晶**：石の 中に かたまりで 混ぜる。洞窟の 床には あかりけっしょうが まばらに 生える。
5. **木**：4マスごとの 区画に 1本 生えるか どうかを 決める（森 62％・雪原 13％・草原 4.5％）。雪原の 木は 上に 雪が のる。
6. **おはな**：草原。花畑に なる 所（14％）と まばらな 所（0.4％）。

### バイオーム（`BIOME`）

| | 決め方 | 表面 | 木 | ほか |
|---|---|---|---|---|
| そうげん（草原） | ふつうの 所 | くさ | 少し | おはな・花畑、うさぎ・ひよこ |
| もり（森） | しめった 所 | くさ | たくさん | うさぎ・ひよこ |
| ゆきはら（雪原） | 寒い 所。**北（z が 小さい 方）ほど 寒い** ので 北に 広がる | ゆき | 雪を かぶった 木 | 水は 上が **こおり**、雪が 降る、ペンギン |
| みずべ（水辺） | 地面が 水面より 低い 所 | すな＋水 | なし | くらげ、つり |

- 割合の 目安（シードで 変わる）：草原 3〜5割・森 2.5〜4.5割・雪原 1.5〜2割・水辺 1〜1.5割。
- スタートは 世界の まん中に いちばん 近い、草原か 森の 陸の 上。
- **雪の 演出**：雪原の 地上に いる 間、のるんの まわりに 白い 点 160こ が 降る（軽い）。

|---|---|---|---|---|

- 掘ると その ブロックが そのまま 素材に なる（置き直せる）。経験値は 3。

### 描画（近くだけ）
- 16×16 の 柱（チャンク）ごとに 形を 作る（世界ぜんたいで 256こ）。**のるんの いる チャンクから 3チャンク先まで（7×7＝49こ）だけ** 作って 描く（`RENDER.radius`）。その 外は 霧（30〜54マス）で かくす。
- 足りない チャンクは 近い 順に **1コマ 2こ まで** 作る（`RENDER.buildPerFrame`）。5チャンク 以上 はなれた 物は 消す。
- 重い 時は `RENDER.radius` を 2 に（5×5＝25こ）、`fogNear/fogFar` も 20/38 くらいに 下げる。

## 2. 明るさ（昼夜・地下・あかり）

値は「画面で 見た 明るさ」の 割合（昼の 地上＝1。`NIGHT`）。

| | 明るさ |
|---|---|
| 昼の 地上 | 100％ |
| 夜の 地上 | 50％ |
| **地下（空が 見えない 所）** | **42％**（夜より 少し 暗い。真っ暗には しない） |
| のるんの すぐ そば（7マス。夜・地下） | 72％まで |
| のるん・敵・動物・ペット（夜・地下） | 72％ |
| あかりけっしょうの そば | 100％（8マスで 0 に なる。かべは すりぬける） |

- **地下の 判定**：柱ごとに「空を さえぎる いちばん 上の ブロック」を おぼえて おく。その 下に 入ると、**5マス 下がる 間に** だんだん 暗く なる（洞窟の 入口は 少しずつ 暗い）。となりの 柱が 明るければ 少し もらう。葉・木・ガラス・こおり等は 空を さえぎらない（木の 下は 暗く ならない）。屋根を 作ると 家の 中も 少し 暗く なる。
- **あかりけっしょう**（19）：置くと 周りを 照らす。洞窟の 床にも 自然に 生えて いる（世界に 300〜450こ）。こわすと 拾える。置く・こわす と、周りの チャンクを 作り直す。
- 仕組み：チャンクを 作る 時、面ごとに「空の 光（0〜1）」「あかりの 光（0〜1）」を 頂点に 持たせる。昼夜の 切りかえは 描く 時の かけ算 だけなので、時間が 進んでも 作り直さない。
- ほしのいし・レア色の いろブロックは 自分の 面だけ 光る（周りは 照らさない）。
- 地下では 霧と 空の 色も 暗く する。

## 3. 動物（敵では ない）

| なまえ | いる 所 | 好物 | 動き |
|---|---|---|---|
| うさぎ | 草原・森 | はっぱ | ぴょんぴょん 跳ねる |
| ひよこ | 草原・森 | きのみ | 小さく 跳ねる |
| ペンギン | 雪原・こおりの 上 | さかな | よちよち 歩く |
| くらげ | 水の 中（深さ 2 以上） | きのみ | ふわふわ 泳ぐ（水の 外へは 出ない） |

- 形は コードで 作る（敵ぷに と 同じ 水準）。**たたいても 当たらない・のるんに 当たっても 何も 起きない**。
- **にげる 子（半分）と にげない 子** が いる。にげる 子は 3.2マス 以内に 近づくと 走って はなれる。
- **餌**：好物を ホットバーで えらんで、そば（2.6マス）で「おく」ボタン → ハートが 出て、**40秒 ついて くる**（にげる 子も にげなく なる）。好物で ない 物を 出すと「うさぎは はっぱが すき」と 出る。
- 数：のるんの 近く（10〜28マス）に、2.5秒ごとに 1ぴきずつ、**同時に 8ひきまで**。46マス はなれたら 消える。場所の バイオームに 合った 種類が 出る。

## 4. 持ち物画面 と マス目クラフト

- 右上の「🎒 もちもの」（パソコンは C か I）。**さぎょうだいの 近くに 来ると 自動で 開く**（v2 と 同じ 条件）。
- **持ち物は 36マス**：ホットバー 9（画面の 下に ならぶ ぶん）＋ かばん 27。1マスに 同じ 物を **99こ まで** 重ねられる。
- 操作（タッチ向け）：
  - マスを タップ → その 物を「持つ」（ピンクの わく）。もういちど タップで やめる。
  - 持った まま **別の マスを タップ → 入れかえ**（同じ 物なら 重ねる）。
  - 持った まま **クラフトの マスを タップ → その 物を 置く**（持ち物は 動かない。目じるしを 置く だけ）。もういちど で 外す。
  - 右の **できあがりの マスを タップ → 作る**（材料が へる。くりかえし おせば 続けて 作れる）。
- **クラフトの マス目：手元は 2×2、さぎょうだいの 近くは 3×3**。形が レシピと 合った 時だけ 完成品が 出る。左右を 反対に 置いても よい。上下左右の 位置は どこでも よい。
- **📖 レシピ本**：作れる 物の 一覧（20こ）。えらぶと **材料が 自動で マスに ならぶ**。材料が 足りない 物・3×3 が いる 物（手元の 時）・もう 持って いる 道具は 薄く 出る。
- 食べ物は、持って「🍴 たべる」。

## 6. ハート・おなか・経験値

- 画面の 下、ホットバーの すぐ 上に：**左に ハート 6・まん中に レベル・右に おなか 6**、その 下に **経験値バー**。クリエイティブでは かくす。
- **おなか**：55秒で 1つ へる。たたく・ジャンプでも 少し へる（1回 0.02）。
  - 食べ物：**さかな ＋2**（つり）／**きのみ ＋1**（はっぱを こわすと 30％で 落ちる）／**ほしクッキー ＋3**（きのみ 2つで 作る）。

  - **空っぽの 間**：ハートが 回復しない＋歩く 速さが 0.8倍。**ハートは へらない**（おなかで やられる ことは 無い）。
- ハート：おなかが 空っぽで なければ、14秒 ぶじだと 1つ もどる。ベッドでも 満タン。
- **経験値**：ブロック 1・鉱石 3・つり 3・敵 5・きんのぷに 15。次の レベルまで ＝ 10 ＋ レベル × 5。上がると 音・表示・Lv の 数字が はねる。**レベルで 解放される 物は 無い**（数字が 増える だけ）。

## 8. モード（クリエイティブ⇔サバイバル）
- 左上の ボタン（⛏ サバイバル／✨ クリエイティブ）を **1回 おすと 切りかわる**。メニューにも ある。スロットごとに 保存。
- **クリエイティブ**：
  - 置いても 素材が へらない。持ち物画面の 下に「ぜんぶの そざい」（23種）が 出て、おすと 99こ 入る。材料 なしで クラフトできる。
  - 色が 24色 ぜんぶ 使える（いろブロック・おえかき・帽子）。※ 解放の 記録は 変わらない。
  - ハートと おなかが へらない（敵に 当たっても はじかれる だけ）。ハート・おなか・経験値の 表示は かくす。経験値は 増えない。
  - **ジャンプを すばやく 2回 → 空を とぶ**。おして いる 間 のぼり、はなすと その 高さで 止まる。もう 2回で やめる（落ちる）。地面に つくと 自動で やめる。とんで いる 間は 1.6倍 速い。
- **サバイバル**：今までどおり（集めた 分だけ）。戻した 時、クリエイティブで えらんで いた 未解放の 色（いろブロック・帽子）は 解放ずみの 色に 戻る。

## 9. 視点（一人称⇔三人称）
- 右上の 👁 ボタン（パソコンは F）。既定は 三人称。スロットごとに 保存。
- **一人称**：カメラは のるんの 目の 位置（足もと ＋ 高さの 82％ ＝ 約 0.72マス）。のるんの 体・かげ・名札は 映さない。持って いる 道具や 描いた 武器が **画面の 右下** に 見え、たたくと ふる。照準は いつも 画面中央。上下は ±83度 まで 見られる。
- **三人称**：今までどおり。

## 10. プレイヤー名 と 名札
- スロットごとに **プレイヤー名**（遊ぶ 人の 名前。10文字まで。初期値「のるん」）。スロットの 名前（データ1 など）とは 別。
  - 変える 所：あそびの 中の メニュー、または タイトルの「⋯」（データが ある スロット）。
- のるんの 頭の すぐ 上に **小さな 名札**（はば 1マス ぶん）。一人称の 時と、カメラが 近すぎる 時（2.2マス 以内）は 出さない。
- 作り：`nametag.js` の `NameTag`。文字を 小さな 絵に して、いつも カメラを 向く 板（スプライト）で 出す。**将来の 通信プレイでは、ほかの 人の キャラクターにも `new NameTag("なまえ")` を 1つずつ 付ければ 同じ 形で 出る**（今回は 通信は 作って いない）。

## 共有（v2 の まま）
- Firebase Realtime Database の REST。あいことば 1つ＝最新 1件。`SHARE.dbUrl` は **仮の 値の まま**（その 間は「じゅんびが まだだよ」と 出る だけ）。
- 場所だけ `…/norun-craft/v3/shares/<あいことばの SHA-256>.json` に 変わった（中身の コードが v3 の ため）。

### 共有の 準備（おうちの 人が 1回だけ）
1. https://console.firebase.google.com/ で プロジェクトを 作る。
2. 「構築」→「Realtime Database」→「データベースを 作成」→「ロック モードで 開始」。
3. 「ルール」タブを 下の 内容に 置きかえて「公開」：

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "norun-craft": {
      "v3": {
        "shares": {
          "$key": {
            ".read": "$key.length === 64",
            ".write": "$key.length === 64 && newData.exists()",
            ".validate": "newData.hasChildren(['data', 'savedAt']) && newData.child('data').isString() && newData.child('data').val().length < 600000 && newData.child('data').val().beginsWith('NORUNCRAFT3.') && newData.child('savedAt').isNumber() && (!newData.child('name').exists() || (newData.child('name').isString() && newData.child('name').val().length <= 12))",
            "$other": { ".validate": "$other === 'data' || $other === 'name' || $other === 'savedAt'" }
          }
        }
      }
    }
  }
}
```

4. 「データ」タブの 上の URL を コピーして、`src/config.js` の `SHARE.dbUrl` に 書く。
- 意味：一覧は だれも 読めない。あいことばを 知って いる 人だけ が その 1件を 読める・上書き できる。消せない。ログインは 使わないので、**あいことばは 長めに**。

## たしかめ方
- `index.html?debug` の 時だけ `window.__nc` が 使える。ボットは 画面を 実際に さわって 操作し、状態を ここから 読む。時間の かかる 準備だけ（素材を 配る・生き物を そばに 出す・時刻を 変える・目的の 場所へ 移動・運を 固定）は ここから 行う。`?debug&seed=数字` で シードを 固定。
- 自動検証は **130項目**。中身：
  - **①** 256×256×40／同じ シードで 同じ 地形・ちがう シードで ちがう 地形／セーブが 差分だけ（世界を 保存して いない）
  - **②** 4つの バイオームが ある／雪原は 北・こおり・雪を かぶった 木・雪の 演出／起伏と 花／ゆきを 掘って 置く・ゆきだるま・こおりに 立つ
  - **③** 洞窟（深いほど 広い）・鉱石の 深さ・光る 結晶／地下は 42％／あかりを 置くと 明るく、こわすと 暗く／ほしのいしを 掘る／ほしの 道具と あかりけっしょうを 作る／ほしの 道具の 回数
  - **④** 好物で ついて くる・好物で ないと 受けとらない／たたいても 当たらない／にげる 子と にげない 子／草原・雪原・水に それぞれの 動物が 出る
  - **⑤** 36マス・2×2／手で ならべて 作る／形が 合わないと 出ない／入れかえ／レシピ本の 薄い 表示と 自動配置／3×3 は 作業台／**20この レシピを ぜんぶ マス目で 作る**／形の 向き
  - **⑥** HUD の 並び／おなかが 時間で へる／たべる（さかな・クッキー・きのみ）／空っぽの 間は 回復せず おそい／経験値（ブロック・鉱石・敵）・レベルアップ
  - **⑦** 1タップで 切りかえ／置いても へらない／ぜんぶの 素材／材料 なしで 作れる／24色／ハートと おなかが へらない／二段ジャンプで とぶ・やめる／サバイバルに 戻すと へる
  - **⑧** 一人称で カメラが 目の 位置・体が 映らない・道具が 見える・照準 中央／一人称でも 歩く・見る・こわす
  - **⑨** 名札の 表示・変更・一人称で かくす・ほかの キャラクターにも 付けられる
  - **⑩** 24色・レア色 8・入手が 別／きんのぷに・ほしのいし・大物で レア色／レア色の いろブロック（つや・発光）／帽子の 色（変える・戻す・星と ピンズは そのまま）
  - **FPS**：描く チャンクの 数／三角形・描画回数・1コマの 処理時間／歩きながら（新しい 所を 作りながら）の コマの 間かく
  - v2 までの 項目：基本操作・叩く・ベッド・夜・おえかき・敵・つり・スロット・コード・共有（モック）・再読みこみ・自動保存・PWA・5通りの 画面・パソコン・当たり判定
- 結果：シード 20261115 で 130項目 すべて 合格。別の シード（777）でも 1回 通して 126項目 合格・4項目 不合格で、不合格は どれも 検証の 側の タイミング（下の「検証機が おそい」ため）だった。そこを 直した あとの 通しは シード 20261115 だけ。
- ボットが 見つけて 直した 不具合：
  - **タイトルで 名前を 変える・コードを 書き出す と、その データの 持ち物が 消える**（しらべた あとの 持ち物の 形が 保存の 形と ちがって いた）
  - 持って いた 物を 使いきった あとも「持って いる」あつかいが 残り、次の タップで 入れかえに なる
  - 近くに 水が あっても、陸の 動物で 8ひきが うまって くらげが 出ない
- 検証機が おそい（ソフトウェア描画で 5〜20fps）ので、右下の 4つの ボタンは ボタンに タッチの できごとを 直接 起こして 押して いる（外からの タッチだと おしっぱなし あつかいで 連打に なる ため）。パッド・スワイプ・おえかき・メニュー類は 外からの タッチ。二段ジャンプの「すばやく 2回」も 同じ 理由で、できごとを 続けて 起こして 確かめた。
- 速さの 実測（この 検証機）：描く チャンク 49こ、三角形 約 9.5万、描画回数 約 50、1コマの 処理（描画の 命令を 出す まで）平均 1.7〜5.4ms・歩きながらの 最大 5ms。世界を 作る 時間は 起動時に 約 1.8秒。**fps そのものは 6fps 前後しか 出て おらず、これは GPU が 無い ため**。タブレットで 何fps 出るかは この 数字からは 分からない。
- 検証は パソコンの ヘッドレス Chrome（**GPU なしの ソフトウェア描画**）。ここで 出る fps は タブレットの fps では ない。**実機の タブレットでの 速さ・さわり心地は まだ 見て いない**。共有は 本物の Firebase とは つないで いない（モックまで）。
