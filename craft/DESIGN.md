# のるんクラフト（仮） 設計メモ（v2）

のるんが 主役の、ブロックで できた 世界を 歩いて「たたく・おく・つくる・かく」ゲーム。

- v1：世界・視点と 移動・こわす／おく・素材9種・保存・PWA
- **v2（この 版）**：夜の 暗さ／セーブ4つ／あいことばで 共有／叩いて こわす＋道具と クラフト／描いた 絵が 武器・ペット・道具に なる／敵と 戦闘／色集め／つり
- マイクラ本家の 絵・名前・音・キャラクターは 使って いない。ブロックの 絵・道具の 絵・敵・色の 名前・効果音は ぜんぶ 自作（コードで 生成）。
- 構成は v1 の まま：`index.html` ＋ `src/` ＋ `lib/`（Three.js r160＋GLTFLoader を 同梱）。importmap。外部CDN・ビルド・新しい ライブラリ なし（おえかきは 標準の Canvas）。
- フォルダを そのまま GitHub Pages に 置けば 動く。
- **v1 の セーブは 引きつがない**（キーも 形も 別。v1 の データは 読まずに 残るだけ）。

## 変えて いない もの（v1 の まま）
- 世界：48×48マス・高さ24。地形の 作り方（平地＋丘4＋水たまり3＋木）。位置番号＝`x + 48 × (z + 48 × y)`。

## 1. 昼と 夜

- 1日 ＝ 480秒。前半が 昼、後半が 夜（さかい目で ゆっくり 変わる。朝夕は 少し オレンジ）。左上に 🌞／🌙。
- **夜は 空だけで なく、照明ごと 落とす**。数値は「画面で 見た 明るさ」の 割合（`config.js` の `NIGHT`）：

| | 昼 | 夜 |
|---|---|---|
| ブロック（地形） | 100％ | **50％**（`NIGHT.blocks`） |
| のるんの すぐ そば（7マス 以内）の ブロック | 100％ | 72％まで（`NIGHT.near`。はなれるほど 50％へ） |
| のるん・敵・ペット・持って いる 物 | 100％ | 72％（`NIGHT.chars`。ライトの 強さを 下げる） |
| 空 | 水色 | こい 紺 |

- v1 で 実機が 暗く ならなかった 理由：v1 は 計算用の 明るさを 0.42倍 に して いたが、画面に 出る 時に 明るさが 持ち上がる（ガンマ）ため、見た目は 7わり近く 残って いた。v2 は **見た目で 50％** に なる ように 計算し直した（計算用の 値は 0.5 の 2.2乗 ＝ 約0.22倍）。
- のるんの 周りの 明かり：ライトを 足すのでは なく、ブロックの 色に「のるんからの きょり」で かけ算 するだけ（軽い）。
- 検証：昼と 夜で 画面の 地形の 明るさを 測り、夜が 昼の 45〜55％ に 入る ことを 確認（実測 50％前後）。

## 2. セーブ（4スロット）

- さいしょに **タイトル**（データを えらぶ 画面）が 出る。スロット 4つ。カードを おすと「つづきから」か「あたらしく はじめる」。カードには **名前・更新日時・見つけた 色の 数**。
- カードの「⋯」で スロットごとの メニュー：**なまえを かえる**（12文字まで。初期値は「データ1」〜「データ4」）／コードを かきだす／コードを よみこむ／あいことばで おくる／あいことばで うけとる／けす。
  - データの ある スロットへの 読みこみ・受けとり・けす は、**もういちど おして 確認** してから。
- あそびの 中の メニュー（☰）：ほぞん／コードを かきだす／あいことばで おくる／データを えらびなおす（タイトルへ）。
- 自動保存：変更の 2秒後／20秒ごと／画面を 閉じる・かくす 時／タイトルへ もどる 時。

  "inv": { "3": 5, "7": 8, "16": 7, "40": 1, "41": 2 },

  "colors": ["shiro", "kuro", "aka", "ao", "ki", "midori"],

    "tools": { "pick": { "img": "data:image/png;base64,…", "area": 0.05 }, "axe": null, "shovel": null, "rod": null }

**v1 からの 変更点**

| 項目 | v1 | v2 |
|---|---|---|
| `v` | 1 | **2**（v1 の データ・コードは 読まない） |
| キー | `norun-craft-save-v1`（1つ） | `norun-craft-v2-slot-0〜3`（4つ）＋`norun-craft-v2-names` |
| `name` | — | スロットの 名前（コードで 運ぶ 用） |
| `inv` | ブロックだけ | ブロック（いろブロックは 色に かかわらず `16` に まとめる）＋ `40` ぼう・`41` さかな |
| `sel` | ホットバーの 枠番号 | **持ち物の 番号**（ホットバーの 枠が 増減する ため） |
| `tools` | — | 道具の 段階（0＝なし、1＝木、2＝石。つりざおは 0／1） |
| `held` | — | 手に 持って いる 物（`hand`/`pick`/`axe`/`shovel`/`rod`/`weapon`） |
| `colors`・`colorSel` | — | 解放した 色の key／いろブロックで えらんで いる 色 |
| `art` | — | 描いた 絵（武器3・ペット3・道具4種）。PNG の data URL（192×192）と、ぬった 広さ `area`（0〜1） |
| `equip` | — | 装備中の 武器・呼んで いる ペットの 枠番号（−1＝なし） |
| `hp`・`respawn`・`enemiesOn` | — | ハート／復活地点（ベッドで ねた 所。null＝世界の スタート）／敵の ON・OFF |
| `changes` | 同じ | 同じ（生成直後と ちがう マスだけ。ブロック番号に 12〜14・16〜31 が 増えた） |
| コードの 頭 | `NORUNCRAFT1.` | **`NORUNCRAFT2.`** |

- 色の 解放状況と 描いた 絵は **スロットごと**（上の とおり スロットの データの 中に 入る）。
- 読みこむ 時に 形を しらべて おぎなう（`save.js` の `check`）：知らない 色・持ち物は 捨てる、さいしょの 5色は かならず 入れる、絵は PNG の data URL で 30万文字 以内の 物だけ、装備は 絵が ある 枠だけ。

### 書き出し・読みこみコード（スロット単位）
- 形：`NORUNCRAFT2.` ＋ 上の JSON を base64url に した 文字。絵が 入るので 長く なる（絵 なしで 300文字ほど、絵 1まいで ＋数千文字）。
- 読みこむと、その スロットの 名前が 初期の まま（データ3 等）なら 相手の 名前を もらう。名前を 付けて ある スロットは その 名前の まま。

## 3. 端末の 間の 共有（あいことば）

- 方式：**Firebase Realtime Database の REST**（`fetch` だけ。SDK なし）。`src/share.js`。
- 「あいことば」1つ ＝ **最新の セーブ 1件**（同じ あいことばで 送ると 上書き）。
- 送る：スロットの メニュー、または あそびの 中の メニューの「あいことばで おくる」。
- 受けとる：タイトルで **入れたい スロット** の「⋯」→「あいことばで うけとる」。えらんだ スロットに 保存される（いま あそんで いる スロットを 勝手に 上書き しない。データが ある スロットは 確認が 出る）。
- 通信の 中身：
  - 場所：`<dbUrl>/norun-craft/v2/shares/<キー>.json`
  - キー：`"norun-craft:" ＋ あいことば`（前後の 空白を 取り、全角半角を そろえた 物）の **SHA-256**（16進 64文字）。**あいことば そのものは 送らない**。
  - 送る：`PUT` で `{ "data": "<書き出しコード>", "name": "<スロットの 名前>", "savedAt": <時刻> }`
  - 受ける：`GET`。無ければ `null` が 返る → 「みつからなかったよ」。
- あいことばは 4文字 以上。
- 使えない 時の 表示（あそびには 影響しない）：
  - ネットが ない → 「いまは ネットに つながって いないので、きょうゆうは つかえないよ」
  - URL が 初期値の まま → 「きょうゆうの じゅんびが まだだよ」（通信は しない）
  - その他の 失敗 → 「うまく つうしん できなかったよ」
- Service Worker は よその サーバーへの 通信に さわらない。

### 共有の 準備（おうちの 人が 1回だけ）

1. https://console.firebase.google.com/ で プロジェクトを 作る（Google アナリティクスは 不要）。
2. 左の「構築」→「Realtime Database」→「データベースを 作成」。場所は どこでも よい。「ロック モードで 開始」を えらぶ。
3. 「ルール」タブを 開き、下の 内容に **ぜんぶ 置きかえて**「公開」：

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "norun-craft": {
      "v2": {
        "shares": {
          "$key": {
            ".read": "$key.length === 64",
            ".write": "$key.length === 64 && newData.exists()",
            ".validate": "newData.hasChildren(['data', 'savedAt']) && newData.child('data').isString() && newData.child('data').val().length < 600000 && newData.child('data').val().beginsWith('NORUNCRAFT2.') && newData.child('savedAt').isNumber() && (!newData.child('name').exists() || (newData.child('name').isString() && newData.child('name').val().length <= 12))",
            "$other": { ".validate": "$other === 'data' || $other === 'name' || $other === 'savedAt'" }
          }
        }
      }
    }
  }
}
```

4. 「データ」タブの 上に 出て いる URL（`https://〇〇-default-rtdb.firebaseio.com` や `https://〇〇-default-rtdb.asia-southeast1.firebasedatabase.app`）を コピー。
5. `src/config.js` の `SHARE.dbUrl` を その URL に 書きかえて、GitHub Pages に 上げ直す。

**この ルールの 意味（家族向けの 最小設定）**
- 一覧は だれも 読めない（`shares` の 上では 読み書き 不可）。**あいことばを 知って いる 人だけ** が、その 1件を 読める・上書き できる。
- 消す ことは できない（`newData.exists()`）。入れられるのは「コード・名前・時刻」の 3つだけで、コードは 60万文字 まで。
- ログインは 使わない。その かわり、**あいことばを 当てられると 読まれる・上書き される**。だから：
  - あいことばは 長めで、家族しか 知らない 言葉に する（例：「のるんと まほうの たまごやき」）。
  - セーブに 入るのは 世界・持ち物・絵・スロットの 名前だけ。名前に 本名を 入れたく ない 時は あだ名に。
  - 使い終わった データは、Firebase の「データ」タブから 手で 消せる。
- 無料枠（Spark）で 足りる 想定（1件 数十KB、たまに 送るだけ）。

## 4. 叩いて こわす・道具・クラフト

### たたく
- 「たたく」ボタン（v1 の「こわす」）を おすたびに 1回。おしっぱなしで 連打（0.26秒ごと）。パソコンは 左クリック。
- たたくと 音が 鳴り、ブロックに **ヒビ**（4段階）が 出る。3.5秒 たたかないと ヒビは 消える（回数も 0に）。
- **1回で こわれる ブロックは 無い**（どの 道具でも さいてい 2回）。素手でも ぜんぶ こわせる。
- かたさ（たたく 回数）は `items.js` の `HARD`：

| ブロック | すで | 合う 道具 | 木の 道具 | 石の 道具 |
|---|---|---|---|---|
| はっぱ・ガラス・おはな | 2 | — | 2 | 2 |
| くさ・つち・すな | 3 | シャベル | 2 | 2 |
| き・いた・さぎょうだい | 4 | おの | 2 | 2 |
| ベッド | 3 | おの | 2 | 2 |
| いろブロック | 3 | — | 3 | 3 |
| いし | 6 | ピッケル | 3 | 2 |
| れんが | 8 | ピッケル | 4 | 3 |
| みず・そこの いわ | こわせない | | | |

- 合わない 道具・武器・つりざおを 持って いる 時は 素手と 同じ 回数。
- 敵が 2.3マス 以内に いる 時は、ブロックでは なく 敵を たたく（6番）。

### 道具
- 3種：**ピッケル**（いし・れんが）／**おの**（き・いた）／**シャベル**（くさ・つち・すな）。段階は 木 → 石。＋ **つりざお**。
- さいしょは 持って いない。クラフトで 作る。同じ 道具は 1つ（石を 作ると 木から 入れかわる）。こわれない。
- **道具欄**：ホットバーの 横（画面が せまい 時は 上の 段）。「て」・作った 道具・装備した 武器が ならび、**タップで 持ちかえ**。持って いる 物は ピンクの わく＋「もってる」の 札、道具には「き／いし」の 字。のるんも 手に 持つ（たたくと ふる）。パソコンは Q で 持ちかえ。

### クラフト（`items.js` の `RECIPES`）
- 右上の「🔨 つくる」で いつでも 開ける。**さぎょうだいの 近く（2マス 以内）に 来ると 自動で 開く**（いちど はなれる まで もう 開かない。敵が 近い 時・当たった 直後・やられて もどった 直後は 開かない）。
- 🔒 の 付いた 物は さぎょうだいの 近くで だけ 作れる。

| 作る 物 | ざいりょう | 場所 |
|---|---|---|
| いた ×4 | き 1 | 手 |
| さぎょうだい | いた 4 | 手 |
| さかなを たべる（ハート＋1） | さかな 1 | 手 |
| ぼう ×4 | いた 2 | さぎょうだい |
| きの ピッケル／おの／シャベル | ぼう 2 ＋ いた 3 | さぎょうだい |
| いしの ピッケル／おの／シャベル | ぼう 2 ＋ いし 3 | さぎょうだい |
| つりざお | ぼう 3 ＋ いた 1 | さぎょうだい |
| ベッド | いた 3 ＋ はっぱ 3 | さぎょうだい |
| いろブロック ×4 | いし 1 | さぎょうだい |
| ガラス | すな 2 | さぎょうだい |
| れんが ×2 | つち 2 ＋ いし 1 | さぎょうだい |

- 流れ：木を たたく → いた → さぎょうだい → ぼう → 木の ピッケル → 石を 集める → 石の 道具。
- 依頼の「木材」は **いた** と して あつかった（き 1こ から 4まい）。
- v1 で さいしょに 配って いた いた・ガラス・れんが は やめた（作れる ように なった ため）。かわりに **いろブロックを 8こ** 配る。

### ベッド
- 置いて、そば（2マス 以内）で「🛏 ねる」ボタン（パソコンは E）。画面が 暗く なって **朝に なる**・**ハートが 満タン**・**そこが 復活地点** に なる・敵が いなく なる。

## 5. おえかき（描いた 絵が 実体化）

- 右上の「🎨 かく」（パソコンは B）。192×192 の キャンバスに 指・マウスで 描く。
- 色は **解放ずみの 色だけ**（まだの 色は「？」）。太さ 3つ・けしごむ・もどす（20回まで）・ぜんぶ けす。
- タブ 3つ：

| タブ | 枠 | ボタン | どう なるか |
|---|---|---|---|
| ⚔ ぶき | 3つ | ほぞん して もつ／はずす | 絵が そのまま 立てた 板（両面）に なり、のるんが 手に 持つ。「たたく」で ふる |
| 🐾 ペット | 3つ | ほぞん して よぶ／かえす | 絵が 実体化して のるんの ななめ 後ろを ついて くる |
| ⛏ どうぐ | ピッケル・おの・シャベル・つりざお | ほぞん して つかう／もとの みために もどす | クラフトで 作った その 道具の 見た目が 絵に なる（性能は 段階どおり） |

- 枠を えらんで「ほぞん して もつ／よぶ」で、前に 描いた 絵を 呼び出せる。何も 描かずに 保存すると その 枠は 空に なる。
- 描くのに 素材・色は へらない。
- **武器の 強さ**：すで 1／道具 1.5／武器 2 ＋（ぬった 広さ ÷ 0.5、上限 1）× 0.6 ＝ **2.0〜2.6**。画面の 半分 以上を ぬると 最大。差は 小さい（敵の 体力 6 なので、どちらでも 3回）。
- **ペット**：動きは コード（上下に ふわふわ、進む 向きへ かたむく、絵が いつも 見える ように カメラを 向く）。かべは すりぬける。のるんから 5マス 以内に 敵が いると 体当たり（ダメージ 1、1.4秒ごと）。
- 絵は スロットごとに 保存（2番）。

## 6. 敵と 戦闘

### 色モンスターの 一覧（`colors.js` の `MONSTERS`）
自作の「ぷに」。丸い 体に とんがりが 1つ、目が 2つ。形は コードで 作る（色だけ ちがう）。

| なまえ | 色 | 落とす 色（上から 順に） |
|---|---|---|
| あかぷに | 赤 | みかんだいだい → りんごべに |
| あおぷに | 青 | よぞらこん → ぶどうむらさき |
| きいろぷに | 黄 | ぷりんいろ → くりちゃいろ |
| みどりぷに | 緑 | はっぱみどり → わかばきみどり |

- 体力 6。のるんが 9マス 以内に 来ると ぴょんぴょん 近づく（速さ 1.7マス/秒。のるんは 4.3 なので 逃げられる）。ふだんは うろうろ。1段は のぼる。
- 出現：草・砂の 上、のるんから 9〜16マス はなれた 所。**昼は 14秒ごとに 1ぴき・同時に 2ひきまで、夜は 7秒ごと・4ひきまで**。
- のるんの 体力：**ハート 6**（左上）。敵に 当たると 1つ へり、はじかれる。当たった あと 1.5秒は 無敵（ちかちか）。25秒 ぶじだと 1つ もどる。さかな・ベッドでも 回復。
- **ゼロに なったら 復活地点（ベッドで ねた 所。なければ 世界の スタート）へ もどるだけ**。ハートは 満タン、持ち物・色・道具・絵は そのまま。
- 攻撃：「たたく」で 2.3マス 以内の いちばん 近い 敵に 当たる（向きは 自動）。敵は 少し はじかれる。＋ ペットの 体当たり。
- たおすと **60％** で その 色の なかまの 色を 落とす（7番）。
- **敵の ON／OFF**：右上の 👾 ボタンを 1回 おすだけ。OFF に すると 今 いる 敵も 消えて、出なく なる（スロットごとに 記憶）。

## 8. つり

- **つりざお**（クラフト）を 作ると、水の そば（3.6マス 以内）で「🎣 つり」ボタンが 出る（パソコンは E）。作るまでは 出ない。
- おすと うきを 投げる →「まつ…」（2〜5.5秒）→ 魚が かかると ボタンが 黄色く ゆれて「❗ ひく！」＋音 → **1.4秒 以内に おす** と つれる。
  - かかる 前に おすと にげる。おさないと にげる。その場から 0.8マス 動くと やめる。
- つれる 物：**色（18％。そらみずいろ → よぞらこん → ぶどうむらさき の 順。ぜんぶ 持って いれば 出ない）**／**素材（のこりの 16％。ガラス・れんが・いろブロック）**／それ以外は **さかな**（持ち物に 入る。「つくる」画面で 食べると ハート＋1）。

## たしかめ方
- `index.html?debug` の 時だけ `window.__nc` が 使える。ボットは 画面を 実際に さわって 操作し、状態を ここから 読む。**時間の かかる 準備だけ**（素材を 配る・敵を そばに 出す・時刻を 変える・水辺や おはなの 前へ 移動・運を 固定）は ここから 行う。`?debug&seed=数字` で 地形を 固定、`?debug&share=URL` で 共有先を 差しかえ。
- 自動検証（104項目。地形を 変えて 3通り）：
  - **①夜**：照明の 設定が 下がる／画面の 地形の 明るさが 昼の 45〜55％／のるんの 周りだけ 少し 明るい
  - **②スロット**：4つ・名前・更新日時／スロット2を 作ると 別の 世界で まっさら／名前を 変える／切りかえて 世界・持ち物・道具・色・絵・装備が そのまま／消す／再読みこみ・自動保存
  - **③共有（通信層は モック：Firebase の REST の まねを する 偽サーバー）**：PUT の 先が ハッシュで、あいことばが URL にも 中身にも 無い／えらんだ スロットへ 受けとって 同じ 世界／ほかの スロットは 変わらない／同じ あいことばは 上書き／ちがう・短い あいことば／オフラインの 表示と あそびの 続行／URL 未設定
  - **④かたさ・道具・クラフト**：かたさの 表 ぜんぶ／1回では こわれず ヒビ／さぎょうだい なしでは 作れない／き→いた→さぎょうだい／近づくと 開く／ぼう→木の ピッケル→石の ピッケル・おの・シャベル・つりざお・ベッド／石は 木3回・石2回・すで6回、板は おの2回、土は シャベル2回（ゲームの 中で 実際に 置いて たたく）／ベッドで ねると 朝・回復・復活地点
  - **⑤おえかき**：描く・色・太さ・もどす・けしごむ・ぜんぶ けす／武器を 保存して 装備・3枠の 呼び出し・はずす／ペットが 出て ついて くる／道具の 絵
  - **⑥敵**：武器で 3回で たおす／色を 落とす／ペットの 体当たり／当たると ハートが へる／ゼロで もどるだけ／自然に 出る／OFF で 消える
  - **⑦色**：16色・ひらがな・出どころ／いろブロックを 色を えらんで 置く／パレットに 出る／おはなで 色
  - **⑧つり**：つりざお なしでは 出ない／早すぎると にげる／魚・色・素材が つれる／魚を 食べる
  - v1 からの 項目：歩く・見まわす・ジャンプ／5通りの 画面で 重ならない（ホットバー 12枠・道具欄 5枠の いちばん 混む 状態で）／パソコン操作／当たり判定／PWA の オフライン起動
- ボットが 見つけて 直した 物：のるんが やられた しゅんかんに エラーが 出る（敵の 一覧を 消しながら 回して いた）／カメラが 葉の 中に 入ると ねらいが おかしく なる／たたかい中・復活直後に クラフト画面が 開いて しまう。
- 検証は パソコンの ヘッドレス Chrome（ソフトウェア描画）。**実機の タブレットでの 速さ・さわり心地・夜の 見え方は まだ 見て いない**。共有は **本物の Firebase とは つないで いない**（モックまで）。
