# のるんクラフト（仮） 設計メモ（v1・核）

のるんが 主役の、ブロックで できた 世界を 歩いて「こわす・おく」ゲーム。
v1 は **核だけ**（世界・視点と 移動・こわす／おく・素材・保存・PWA）。敵・戦闘・描く 機能・通信・クラフトは 入れて いない（v2 以降）。

- マイクラ本家の 絵・名前・音・キャラクターは 使って いない。ブロックの 絵と 効果音は ぜんぶ コードで 自動生成した 自作の もの。
- 構成は『のるん まなび』と 同じ流儀：`index.html` ＋ `src/` ＋ `lib/`（同梱）。外部CDN なし・ビルド なし。
- フォルダを そのまま GitHub Pages に 置けば 動く（`.nojekyll` 入り）。

## 世界

- 大きさ：**48 × 48 マス、高さ 24**（`WORLD.sx / sz / sy`）。ぜんぶで 55,296 マス。1マス＝1バイト（ブロックの 番号）。
- 位置番号：`x + 48 × (z + 48 × y)`（x・z が 横、y が 高さ。y=0 が いちばん 下）。
- 描画は 16×16 の 柱（チャンク）ごとに 1つ ＝ 3×3 の 9こ。ブロックを 変えたら その チャンク（はしなら となりも）だけ 作り直す。
- 世界の はしは 見えない かべ。いちばん 下（y=0）は こわせない「そこの いわ」。世界は 雲の 海の 上に ういて 見える。

### 地形の 自動生成（`generate(seed)`）
- **同じ seed からは かならず 同じ 地形** が できる（だから セーブは「seed ＋ 変えた 所だけ」で すむ）。
- 平地：地面の あつさ 7（いちばん 上は y=6）。なめらかな でこぼこ ±1 くらい。
- 丘 4つ（高さ ＋3〜6、半径 5〜8）、水たまり 3つ（深さ 3 くらい、半径 4〜6）。スタート（まんなか）の まわり 3マスは 平ら。
- 層：y=0 そこの いわ／その 上 いし／上から 2〜3マス目 つち／いちばん 上 くさ。水たまりの まわりは すな。
- 水面は y=5（地面より 1マス 下）。
- 木 さいだい 14本（みき 3〜4マス＋はっぱ）。いちばん 高い 所でも y=19 くらいで、上限 24 に おさまる。

## ブロックの 一覧

番号は セーブに 入るので **あとから 変えない**（足す 時は 後ろに）。

| 番号 | なまえ | key | ホットバー | メモ |
|---|---|---|---|---|
| 0 | （なにも ない） | air | — | |
| 1 | くさ | grass | 1 | 上が 草・横が 草＋土・下が 土 |
| 2 | つち | dirt | 2 | |
| 3 | いし | stone | 3 | |
| 4 | すな | sand | 4 | 水たまりの まわり |
| 5 | き | log | 5 | 木の みき（上下に 年輪） |
| 6 | はっぱ | leaf | 6 | |
| 7 | いた | plank | 7 | 世界には 生えて いない。さいしょに 24こ 配る |
| 8 | ガラス | glass | 8 | むこうが 見える。さいしょに 12こ |
| 9 | れんが | brick | 9 | さいしょに 12こ |
| 10 | みず | water | — | 通りぬけられる・ねらえない・こわせない。中は ゆっくり、ジャンプで およぐ。流れない |
| 11 | そこの いわ | rock | — | こわせない（世界の 底） |

- こわすと **その ブロックを そのまま 1こ** 拾う（くさは くさの まま）。持てる 数は 1種類 999 まで。
- いた・ガラス・れんがを さいしょに 配るのは、v1 に クラフトが ない ため（`START_INV`。v2 で 0 に する 想定）。
- 水の 中に ブロックを 置くと 水は 消える。水は 流れない（v1）。

## のるん（モデル）

- `assets/models/norun-v7.glb` を **Three.js の GLTFLoader** で 読む（『まなび』の `norun-model.js` と 同じ流儀。バッジは `findPinSlots()` で モデルの 初期の 見た目＝スロット1の パンダだけ）。
- モデルの 中身：頂点カラー（画像テクスチャ なし）、ふちどりは `KHR_materials_unlit`。**アニメ・ボーンは 入って いない** ので、歩く ゆれ・ジャンプの のび・着地の ぺちゃんこ・息づかいは コードで モデルぜんたいを 動かして いる（`main.js` の `updateNorun`）。
- 大きさは **読みこんだ モデルの 実寸を 測って** 決める（`norun.js`）：

| | モデルの 実寸 | ゲームの 中（マス） |
|---|---|---|
| 体（Body）の はば | 1.54 | **0.95**（これに 合わせて 倍率 0.616） |
| ぜんたいの はば（ぼうしの つば） | 2.22 | 1.37 |
| ぜんたいの 高さ（ぼうしの 先まで） | 1.43 | 0.88 |
| 当たり判定の はば | — | **0.80**（体の 84％。1マスの すき間を 通れる） |
| 当たり判定の 高さ | — | **0.88**（ぼうしの 先まで。高さ 1マスの トンネルを くぐれる） |
| カメラの きょり | — | **4.76**（3.0 ＋ 高さ × 2.0） |
| カメラが 見る 点 | — | 足もと ＋ 1.43（高さ ＋ 0.55。頭の 少し 上） |

- 顔は +Z 向き。進む 向きへ なめらかに 回る。足もとに 丸い かげ（ジャンプの 高さが 分かる）。
- モデルを 差しかえても、体の ノード名が `Body` なら 同じ 計算で 自動で 合う（なければ ぜんたいの はばで 計算）。
- 読みこみに 失敗した 時だけ、白い 丸＋黒い ぼうしの かんたんな 形で 代わりに 動く。

## 視点と 移動

- 3人称。のるんの 後ろ・ななめ 上から 見る。カメラと のるんの 間に ブロックが ある 時は、ぶつかる 手前まで カメラを 寄せる。
- 歩く：4.3マス/秒。パッドの 上＝画面の おく（カメラから 遠ざかる 向き）。
- ジャンプ：高さ 約1.4マス（1マスは とびこえられる、2マスは むり）。
- **1段（1マス）は 歩くだけで 自動で 乗りこえる**。2段より 高い かべは 止まる。乗りこえた 時は 見た目だけ なめらかに 上がる。
- 当たり判定は 箱（はば 0.80 × 高さ 0.88）と ブロック。x → z → y の 順に 動かして、ぶつかったら 手前で 止める。

## 操作

| | タブレット | パソコン |
|---|---|---|
| 歩く | 画面の **左半分** を さわると、その 場所に パッドが 出る（ずらし 46px で 全力。『まなび』第13弾と 同じ） | WASD／矢印 |
| 見まわす | **右半分** を スワイプ。パッドの 指を おいた まま なら、べつの 指は どこでも 見まわし | マウスドラッグ |
| ジャンプ | 右下の ボタン | スペース |
| こわす | 「こわす」ボタン（おしっぱなしで 連続） | 左クリック |
| おく | 「おく」ボタン（おしっぱなしで 連続） | 右クリック |
| えらぶ | 下の ホットバーを タップ | 1〜9・ホイール |

- ねらい：タッチは **画面の まんなかの 照準**（＋）、マウスは **カーソルの 先**。ねらった ブロックは 黄色く 光って 白い ふちが 出る。
- とどく きょり：のるんの 体の まんなかから **4マス**（`PLAYER.reach`）。
- 置く 場所は ねらった 面の となり。のるんに めりこむ 所・世界の 外・高さ 24 より 上には 置けない。
- 左半分＝パッド／右半分＝見まわし に 分けたのは、1本指だけでも 見まわせる ように する ため。
- ボタンの 上を さわった 時は パッドは 出ない。

## 保存形式

### localStorage
- キー：`norun-craft-save-v1`。中身は 下の JSON。
- **自動保存**：ブロックを 変えたら 2秒後／そうで なくても 20秒ごと／画面を 閉じる・かくす 時。＋ メニューの「ほぞん する」。

```json
{
  "app": "norun-craft",
  "v": 1,
  "size": [48, 24, 48],
  "seed": 1881949943,
  "changes": [14235, 0, 23871, 4],
  "inv": { "4": 1, "7": 24, "8": 12, "9": 12 },
  "sel": 3,
  "player": { "x": 33.02, "y": 10, "z": 13.31, "yaw": -2.25, "pitch": 0.8 },
  "time": 61,
  "savedAt": 1794000000000
}
```

| 項目 | 中身 |
|---|---|
| `app`・`v` | 目じるしと 版。ちがう 物は 読まない |
| `size` | 世界の 大きさ [x, y, z]。ちがう 大きさは 読まない |
| `seed` | 地形の 種。ここから 生成直後の 地形を 作り直す |
| `changes` | **生成直後と ちがう マスだけ**。`[位置番号, ブロック番号, 位置番号, ブロック番号, …]`。もとに 戻した マスは 消える |
| `inv` | 持って いる 素材。`{ ブロック番号: 数 }`（0の 物は 書かない） |
| `sel` | えらんで いる ホットバーの 枠（0〜8） |
| `player` | のるんの 位置と カメラの 向き |
| `time` | 1日の 中の 時刻（秒。0〜480） |
| `savedAt` | 保存した 時刻（参考） |

### 書き出し・読みこみコード（将来の コード交換用）
- 形：`NORUNCRAFT1.` ＋ **上と 同じ JSON を base64url に した 文字**（`save.js` の `toCode` / `fromCode`）。
- メニューの「コードを かきだす」で 出て（コピー ボタン つき）、「コードを よみこむ」に はりつけると その 世界に なる（いまの 世界は 上書き）。
- 読みこむ 時に 形を しらべる（`check`）。目じるし・版・大きさが ちがう／こわれて いる コードは ことわって、いまの 世界は そのまま。
- 版を 上げる 時は 頭の `NORUNCRAFT1.` の 数字と `v` を 上げる。

## 昼と 夜（おまけ）
- 1日 ＝ 480秒（`DAY_LEN`）。空の 色と 明るさが ゆっくり 変わる（朝夕は 少し オレンジ）。夜でも 明るさ 42％ までで、まっくらには しない。
- ブロックは 光の 計算を せず、面の 向きごとの 明るさ（上 1.0・横 0.82/0.7・下 0.55）× 時刻の 明るさ だけ（軽い）。のるんだけ ライトで 照らす。

## 軽さの ため
- 見える 面だけ 作る。描画は 9チャンク × 2（不透明＋水）＋ のるん。
- 絵は 64×64 の 1まい。画面の 細かさは 端末の 1.5倍 まで。アンチエイリアス なし。

## PWA
- `sw.js`：さいしょの 読みこみで 22ファイルを ぜんぶ ためる → 次からは オフラインで 起動。
- ためた 物を すぐ 返し、うらで 新しい 物を 取りに 行って 入れかえる（直した ファイルは **次の 次の 起動** で 反映）。すぐ 切りかえたい 時は `sw.js` の `CACHE` の 数字を 上げる。
- **ファイルを 足した 時は `sw.js` の `FILES` に 足す**。

## たしかめ方
- `index.html?debug` の 時だけ `window.__nc` から 状態を 読める（位置・向き・ねらい・持ち物・世界の 指紋）。ボットは ここから **読むだけ** で、操作は 画面を 実際に さわって 行う。`?debug&seed=数字` で 地形を 固定できる。
- 自動検証（48項目・地形を 変えて 3回）：
  - 起動して エラー無く 世界が 出る／のるんが GLB で 出る
  - タッチ：さわった 所に パッド → 歩く → パッドの 指を おいた まま べつの 指で 見まわす → 右下で ジャンプ → 光った ブロックを こわして 拾う → 別の 場所へ 行って ホットバーで えらんで 置く → ほぞん → 再読みこみで 世界の 指紋・持ち物・位置が 一致
  - 自動保存だけでも 続きから／オフラインで 起動／書き出しコードを 別の 端末で 読みこむと 同じ 世界／こわれた コードは ことわる
  - 画面：タブレット 横・縦、スマホ 横・縦、大きい 横 の 5通りで ボタンが はみ出さず 重ならず、ひととおり 動く。途中で 向きを 変えても 追いつく
  - パソコン：WASD・ドラッグ・スペース・左クリック・数字キー・右クリック
  - 当たり判定：1段は 乗りこえる／2段は 止まる／ジャンプの 高さ／世界の はし／天井／1マスの すき間／底
- 検証は パソコンの ヘッドレス Chrome（ソフトウェア描画）で 行った。**実機の タブレットでの 速さ・さわり心地は まだ 見て いない**。

## v2 以降に 回した もの
敵・戦闘・体力や 空腹／武器と ペットを 描く 機能／色集め／釣り／クラフト（ベッド等）／クリエイティブ⇔サバイバル切替／通信。
ほかに v1 で やって いない こと：水が 流れる・ブロックが 落ちる（すな 等）・かげの 計算・BGM。
