# ASMRタワー 設計（たたき台・2026-11-07）

## ねらい
Roblox の「ASMRタワー」のように、**のぼる楽しさ ＋ 素材をふむ気持ちよさ（見た目・音・手ごたえ）** を味わうモード。
アスレ（しかけで遊ぶ）とちがい、**しかけはなし**。素材ごとの「ふみごこち」を主役にする。

## あそびかた
- 操作はアスレと同じ：バーチャルパッドで歩く・ジャンプボタン（パンの時は「すべる」も）。キャラ（変身）もアスレと共通。
- 頂上なし。のった足場のいちばん高い所（m）が記録（アスレとは別の じこベスト）。
- 落ちたら直前の旗から（何回でも OK）。
- BGM は静かな曲（`bgm_asmr.mp3`）。足音が主役。

## コースのつくり
- **区間（ゾーン）** ＝ 1つの素材テーマ。区間のはじめに、テーマ名の看板と旗。
- 1区間 ＝ 部品 `ASMR.sectionParts`（いまは4つ）。部品は かいだん・すき間・高い段・1本道 の4種類だけ（しかけなし）。
- 区間が終わると次のテーマへ（しゃりしゃり → ぷにぷに → ねばねば → しゃりしゃり …）。
- 区間に入ると「○○ ゾーン」と表示、空の色もテーマの色になる。

## 素材テーマのパラメータ（`src/config.js` の `ASMR_THEMES`）

| 項目 | 意味 |
|---|---|
| `walk` | 歩く速さの倍率 |
| `jump` | ジャンプの高さの倍率（その床からとぶ時） |
| `grip` | 止まりやすさ。小さいほど つるつる すべる（ふつう 16） |
| `bounce` | 着地した時に 自動ではねる強さ（0＝はねない）。だんだん止まる |
| `sink` | 着地の しずみこみ（見た目のつぶれ方） |
| `stepEvery` | 足音を鳴らす間かく（歩数）。ねばねば は 2歩に1回で ゆっくり |

見た目は `src/tower3d.js` の `THEME_LOOK`（体の色・空の色・上の面の模様・すけ具合）。模様はプログラムで描いています（画像ファイル不要）。

## いまの3テーマ（たたき台）

| テーマ | 見た目 | 足音（ファイル） | 手ごたえ |
|---|---|---|---|
| しゃりしゃり（かきごおり） | 水色、白いつぶ と きらきら | `step_shari` / `land_shari`「シャクッ」 | つるっと すべる（grip 3.5）。ジャンプふつう |
| ぷにぷに（グミ） | ピンクで少しすける、まるい あわ | `step_puni` / `land_puni`「ぷにっ・ぽよん」 | ジャンプ×1.3、着地で ぽよんと はねる、足場が ふむと へこむ |
| ねばねば（はちみつ） | こはく色、たれる模様 と つや | `step_neba` / `land_neba`「ぬちゃっ」 | 歩く×0.6・ジャンプ×0.8、ぴたっと止まる。段は ひくめに作る |

## テーマの ふやし方（次回の量産）
1. `ASMR_THEMES` に1行足す（id・名前・パラメータ）。
2. `THEME_LOOK` に 見た目（color・sky・tex の描き方）を足す。
3. `assets/audio/step_<id>.mp3`・`land_<id>.mp3` を置く（なくても代わりの音で動く。代わりの音を作りたい時は `src/sound.js` の `STEP_SYNTH`）。
