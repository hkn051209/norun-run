# ASMRタワー 設計（第4弾で 作り直し／第5弾の 実機フィードバックで 登りルート・カメラを 修正・2026-11-07）

## ねらい
Roblox の「ASMRタワー」のように、**四角い部屋を 1かいずつ のぼる ＋ 素材を ふむ 気持ちよさ（見た目・音・手ごたえ）** を味わうモード。
アスレ（チェックポイント式・しかけで遊ぶ）とは **真逆の 仕様** にして、別物感を出す。

参考にした録画（ひこのさん提供）から取り入れたこと：
- 部屋の かべは テーマ色の **2色の 市松もよう**
- 足場は **大きな 物**（キーボードの キーが ならんだ「キーの はたけ」、スライムの プール、クッキー、せんべい …）
- 物と 物の あいだを ジャンプで つないで 上へ

## あそびかた
- 操作は アスレと同じ：バーチャルパッドで 歩く・ジャンプ（キャラの とくぎ ボタンも つかえる）。キャラ（変身）も アスレと 共通。
- 頂上なし。記録は のった足場の いちばん高い所（m）。アスレとは 別の じこベスト。

## 部屋（フロア）の つくり
- 1フロア ＝ 13m 四方の 四角い 部屋（`ASMR.room`）、高さ 7m（`ASMR.floorH`）。1フロア ＝ 1テーマ。
- 床は 2.6m の タイル 5×5。かべ（4まい）は テーマ色の 市松。
- 道は 2つの 区間：
  1. **かべぞいの らせん**（半径 4.3m の 円）。天井（＝上の フロアの 床）の 下なので、**ジャンプしても 頭が つかえない 高さまで** しか 足場を おかない（`hOutMax`）。
  2. **すみの 吹き抜け**（床の 穴 2×2 マス）。天井が ないので、ここで 上の フロアの 高さまで 足場を つむ。吹き抜けの 4すみには **黄色い 柱**（「ここから 上の かいへ」の しるし）。
- 吹き抜けの さいごの 足場は 上の フロアの 床と 同じ 高さ。そのまま 歩いて 上の フロアへ 出る。
- 足場は **下から すりぬけられる**（`oneWay`）。下から とびあがった 時に 頭を ぶつけず、上に のれる。
- らせんは、下から 上がってきた 吹き抜けの 真上を さけて まわる（低い 足場が 下の かいの 出口を ふさがない ように）。
- 床の かざり（大きな 物）は、穴の 上・スタートの そば・落とし穴の 上には おかない。
- 上の フロアの 床（＝天井）は うすく すけて 見える。2つ上 より 上と、3つ下 より 下は かくす。
- 2かい より 上の 床には **落とし穴**（オレンジの ふち）が 1つ（`ASMR.traps`）。
- 第5弾の 実機で あった「まんなかに 黒い 柱が ぶらさがる」は キーの 軸の 絵だったので 消した。「1かいで 上に いけない」は 天井に 頭が つかえる 高さに 足場が あったのが 原因 → 上の 2区間の つくりに 変えた。

## カメラと 操作（第5弾＋実機フィードバック）
- **寄った 視点**（うしろ 少し上）と **一人称視点** を 右上の 👁 ボタンで 切りかえ（パソコンは V）。一人称の 時は キャラを かくす。
- **「まえを むく」ボタン**（⬆・パソコンは F）：キャラと カメラを 次の 足場の 方へ 向ける。
- 画面を スワイプすると 視点が まわる。**指を 右へ → 右を むく**（実機の 感想で 向きを 逆に した）。パソコンは Q・E。パッドの 前 ＝ いま 見ている 方向。
- 上下の 角度は せまく（`pitchMin`〜`pitchMax`）して、へんな 角度に ならない ように した。スワイプを はなして 少し たつと（`follow` 秒）、歩く 方向へ カメラが ゆっくり まわりこむ。
- カメラは 部屋の かべの 外に 出ない。かべで 近く なった時は 少し 上から 見下ろし、見る 点も 手前に よせる（キャラが 画面から 切れない）。
- 横画面：横画面用の CSS を ふつうの 指定より あとに 書きなおした（前は 一部が 上書きされて 効いて いなかった）。高さ 600px 以下の 横画面で ボタンを 小さく・カメラの ボタンは 横ならび。⤢ ボタンで 全画面＋横向き固定（対応している 端末だけ）。
- 数値は `src/config.js` の `ASMR_CAM`。

## 踏み音（第5弾）
足場を **踏んだ 瞬間** に 鳴らす（歩く リズムの 足音では ない）。くわしくは AUDIO.md。

## 落ちた時（チェックポイントなし）
- 穴や 足場の はしから 落ちたら、**ほんとうに 落ちる**。
- 落ちる とちゅうで 下の 足場や 下の フロアの 床に 着地できたら、**そこから つづき**（「○かいに おちた！ ここから つづき」）。
- 吹き抜けや 落とし穴から、下の フロアへ 落ちることも ある。
- 1かいの 床まで 落ちたら、そこが さいしょ（「1かいまで おちた… さいしょから！」）。

テーマの こうもく：walk（歩く速さ）／jump（ジャンプ）／grip（止まりやすさ）／bounce・keep（はね）／grav（重力）／sinkRate・sinkMax（しずむ）／breakT（われる）／press（キーが しずむ）／wobble（ゆれる）／drift（ころがされる）／stepEvery（足音の 間かく）／shapes（足場の 形）。
見た目は `src/asmr-rooms.js` の `LOOK`（空の色・かべの色・足場の色・床の もよう）と `makeShape`（物の形）。


## テーマの ふやし方
1. `ASMR_THEMES` に 1行 足す（id・名前・こうもく・shapes）。
2. `asmr-rooms.js` の `LOOK` に 見た目を 足す。新しい 形が いる時は `makeShape` に 足す。
3. 足音の ファイルを `step_<id>` / `land_<id>` で 置く。
