# のるん まなび　音（BGM・効果音）の作り方と入れ方

## 入れ方（ファイルを置くだけ）
- `assets/audio/` に、下の表の **ファイル名どおり** に置くと、自動で差しかわります（コードの変更は不要）。
- 形式は **mp3**（iPad・iPhone でも確実に鳴るため）。Gemini から wav などで出た場合は mp3 に変換してください。
- ファイルがない音は、今までどおり **ブラウザの音源で鳴る音（ピンポン等）** が代わりに鳴ります。BGM はファイルがないと鳴りません。
- 保護者画面「あそびの せってい」で **BGM／効果音を別々にオン・オフ** できます（端末ごとに保存）。読みこめたファイル名もそこに表示されます。
- ファイル名を変えたいときは `src/sound.js` の `AUDIO_FILES` を直します。音量は同じファイルの `VOL`（BGM 0.32、効果音 0.85）。

## BGM（4曲・ループ再生）

| ファイル名 | 流れる場面 | 長さ | テンポ |
|---|---|---|---|
| `bgm_menu.mp3` | まなび（タイトル・マイページ・学習の選択ラン・保護者画面など） | 30〜60秒 | 90〜100 BPM |
| `bgm_run.mp3` | あそび：ラン | 30〜60秒 | 140〜150 BPM |
| `bgm_tower.mp3` | あそび：アスレ | 30〜60秒 | 110〜120 BPM |
| `bgm_asmr.mp3` | あそび：ASMRタワー（足音が主役） | 60秒 | 70〜80 BPM |

- どの曲も **歌なし（インスト）**・**ループ前提**。曲の終わりから頭へ、切れ目なくつながるのが理想です。
- 結果画面では、直前の曲がそのまま続きます。
- ループのつなぎ目で「プツッ」と鳴る場合は、曲の頭と終わりを0.05秒ほど短くフェードさせると目立たなくなります。

## 効果音（ゲームの中で鳴る音）

すべて **短く、頭に無音を入れない**（押した瞬間に鳴るように）。BGM の上で聞こえる、明るくかわいい音。こわい音・大きすぎる音にはしない。


- **se_bump**（任意）：ぶつかった「ポコッ」。やわらかい木やゴムの音。痛そうにしない。0.4秒。

## 作ったら
1. mp3 にして、上のファイル名で `assets/audio/` に入れる
2. 保護者画面の「読みこめた 音の ファイル」に名前が出ればOK
3. 音量のバランスがおかしいときは、ファイル名と「大きい・小さい」を教えてください（`VOL` か、ファイルごとの音量で調整します）

## ASMRタワーの 素材の 音（第11弾で 考え方を 統一）

**鳴らすのは「足音」では なく、踏んだ 素材 そのものから 出る 音。**（ひこのさん：「足音じゃなく、それを踏んだときに音が出るようにする」）
- 人が 歩く 音（くつの コツコツ・ザッザッ）は 入れない。せんべいなら われる 音、スライムなら つぶれる 音、ビーズなら じゃらっと ながれる 音。
- 鳴る タイミング：
  - 新しい 足場（キー1こ・グミ1こ・せんべい1まい …）に のった 瞬間 → `step`（軽く つぶれる・おされる 音）
  - ジャンプから 強く 着地した 瞬間（ぷにぷに・スライムで はねる 時も）→ `land`（強く つぶれる・われる 音）
  - **プール区間**（第11弾。ビーズ・スライム・かき氷・わたあめ・とろとろチョコ）：歩いて いる 間、0.5〜0.7m ごとに その 素材の `step`（ビーズ＝`koro`・スライム＝`slime`・かき氷＝`shari`・わたあめ＝`fuwa`・とろとろチョコ＝`neba`）。毎回 音の 高さを 少し かえる。
  - プッシュポップは、まだ 押されていない マスに のった 瞬間に ポコッ
  - チョコマシュマロは、はじめて 踏んだ 時は チョコが われる `land`、われた あとは 中の マシュマロが つぶれる `step`（ひくめ）
- 足場の 形ごとの きまり（`src/config.js` の `SHAPE_SOUND`）：スペースバー＝いつも land を ひくめ（0.78）。
- ファイルが 何こか ある テーマは、踏むたびに ランダムで 1つ えらぶ。ない 時は テーマごとの 代わりの 合成音。
- 素材の 録音を さがす 時の きまり（ライセンスなど）は MATERIALS.md。

| 2かい | `puni` | ぷにぷに | グミ・ボタン | `step_puni` | `land_puni` |

| 4かい | `neba` | ねばねば | はちみつの びん・スプーン | `step_neba` | `land_neba` |

（すべて `assets/audio/` に `.mp3` で。ファイルの リストを かえたい時は `ASMR_THEMES` の その テーマに `sounds: { step: [...], land: [...] }` を 書く）

共通の前置き（毎回つける）：
```
子ども向けASMRゲームの「素材の音」を1つ。足音ではありません：人の足音・くつの音・床をたたく音は入れない。
その素材そのものが、押される・つぶれる・われる・こすれるときに出る音だけ。声なし、BGMなし。
頭に無音を入れず、すぐ音が始まるように。耳に心地よい、気持ちいい質感。こわくない、大きすぎない。
```
- **step_key**：キーボードのキーが1つ押しこまれる「カチャッ」。キーのばねと軸の音。0.1秒。
- **land_key**：キーがいくつかまとめて押しこまれる「カタタッ」。0.3秒。
- **step_puni**：グミがぎゅっと押される「ぷにっ」。弾力のある、しめった小さな音。0.15秒。
- **land_puni**：大きなグミがつぶれて戻る「ぶにゅん」。0.4秒。
- **step_shari**：かき氷が押しつぶされる「しゃくっ」。細かい氷の粒がくずれる音。0.15秒。
- **land_shari**：かき氷の山がくずれる「シャクシャクッ」。0.4秒。
- **step_neba**：はちみつ（とろとろの液体）に押しこまれる「ねちょっ」。0.25秒。
- **land_neba**：はちみつに沈みこむ「ぬちゅ〜」。糸を引くような余韻。0.5秒。
- **step_zaku**：クッキーがくだける「ザクッ」。0.15秒。
- **land_zaku**：クッキーが割れてかけらが散る「ザクザクッ」。0.4秒。
- **step_slime**：スライムがつぶれる「ぶちゅっ」。水っぽく、空気がぬける音。0.2秒。
- **land_slime**：スライムが大きくつぶれて戻る「ぶにょ〜ん」。0.5秒。
- **step_fuwa**：わたあめがつぶれる「ふすっ」。空気がぬける、ごく小さな音。0.15秒。
- **land_fuwa**：わたあめの山がしぼむ「ぽふっ」。0.4秒。
- **step_pari**：せんべいにひびが入る「パリッ」。0.12秒。
- **land_pari**：せんべいが割れる「バリンッ」。0.4秒。
- **step_koro**：ビーズの粒がこすれて流れる「じゃらっ」。0.2秒。
- **land_koro**：ビーズの山にしずみこむ「ジャラララ」。0.5秒。
- **step_choco**：チョコの中のマシュマロがつぶれる「ふにゅっ」。0.2秒。
- **land_choco**：チョコのコーティングが割れる「パキッ」＋中がつぶれる「ふにゅ」。0.4秒。
- **step_push**：シリコンのポコッとした所が裏返る「ポコッ」。0.12秒。
- **land_push**：いくつかまとめて裏返る「ポコポコッ」。0.3秒。

（キーボード・しゃりしゃりは `_gen` の 名前で 足すと、いまの 音と ランダムに まざる。上書きで 差しかえても よい）
