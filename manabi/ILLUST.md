# イラストの 指定（ChatGPT で 用意してもらう もの）

`assets/ui/` に 下の **ファイル名どおり** の PNG を 置くだけで、ゲームが 自動で つかいます。
置いていない ものは いまの 絵文字・文字の まま 表示されるので、**1まいずつ 少しずつ 足して OK** です。

## 共通の 指定（毎回 ChatGPT に つける 文）

```
子ども向け学習ゲーム「のるん まなび」のUI用イラスト。
主役キャラ「のるん」：白いおもち のような まるい ねこ。紫の まじょの ぼうし（先が 2つに わかれて くるんと まがる）、ぼうしに 金色の ほしの チャーム。
スタイル：やわらかい パステル、まるい 形、太めの なめらかな ふち線（こい むらさき #4a3470）、影は うすく 1段だけ。
色：ラベンダー #b59cff、ミルク #fffdfb、ピンク #ff8fc2、バター #ffe17a、ミント #6fd6a6、そら #7cc4ff。
背景は 透明（PNG）。文字は 入れない（ロゴだけ 例外）。ほかの 作品の キャラクターや ロゴに 似せない。
```

## 置いたあと
- `assets/ui/` フォルダを 作って そこへ（GitHub Pages なら `manabi/assets/ui/`）。
- 画像が 大きすぎる 時（1まい 300KB 以上）は、PNG を 圧縮（TinyPNG など）してから 置くと 読みこみが 速いです。
