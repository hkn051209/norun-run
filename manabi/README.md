# のるん まなび（算数・国語の選択ラン）

のるんランとは別のアプリです。保存のキーも別（`norunmanabi.v1.〜`）なので、同じサイトに置いても のるんラン のデータとはまざりません。

## 公開のしかた
このフォルダの中身を、のるんランとは別のリポジトリ（または別のフォルダ。例：`/manabi/`）に置き、index.html を開くだけで遊べます。外部サイトは使いません。

## はじめての準備（保護者）
1. タイトル画面の右下「おうちのかたへ（ながおし）」を 2秒 長押し
2. 4けたの暗証番号を決める（2回入力）
3. 保護者画面で、名前・学年・アイコンを選んで「追加する」（3人ぶん。あとから追加も可）
4. お子さまが自分の名前を押すと、さいしょに「すきな絵を3つ」えらんで合言葉を決めます（2回えらんで確認）

## 遊び方（子ども）
- 名前を押す → 合言葉の絵を3つ（じゅんばんは関係なし）→ マイページ
- 年長・小1：「たしざん」→ 5まで（20問正解で 10まで が開く）。問題は自動で読み上げ。🔊でもう一度
- 小2〜小6：「くく」→ 段をえらんで じゅんばん／ランダムで9問
- 📖「こくご」（10問）
  - 年長・小1：🔊ひらがな（読み上げを聞いて、その文字の門へ）／🦊カタカナ（カタカナを見て、読みのひらがなの門へ）
  - 小2〜小6：その学年の漢字。🔤よみ／🈴かんじえらび（読みから漢字）／✍️おくりがな／🎲ミックス
  - 最初のデータは 小4・小5 の分だけ。ほかの学年は「じゅんびちゅう」。保護者画面で その学年の ことばを3つ以上入れると遊べる
  - まちがいの選択肢は、同じ学年の ほかのことば（同じ読みのことば＝機械／機会 などは 入れない）。おくりがなは 1字へらす・ふやす形
- 学習は「選択ラン」：のるんが自動で走りつづけ、問題ごとに 答えの門が3つ（3レーン）あらわれる
  - 画面の下の 大きな ◀ ▶ ボタンで 1レーンずつ移る。左右のスワイプでも移れる（パソコンは ← → キー）
  - 門をくぐると ⭕／❌。まちがえた時は 正解の門が のるんの前で 0.55秒 みどりに光る。のるんは止まらない
  - 障害物・ジャンプはなし（遊びのラン専用）
  - 年長・小1は 門の上の看板と 画面の上に ドットで問題。読み上げも そのまま
- まちがえた問題は「ふくしゅう」に たまり、2回つづけて正解すると「やっつけた！」でリストから外れる
- 九九は 3回つづけて正解すると「おぼえた」。マイページの81マスの表が埋まっていく
- 正解で ポイント（1問1ポイント、5れんぞくごとに +3）。「ぼうし」で帽子の色と交換

## 保護者画面でできること
- 学年の変更、データを消す、合言葉のリセット（子どもの画面からはできません）
- 各自の正解数・おぼえた九九の数・復習の数・ポイントの確認
- バックアップの書き出し（ファイル／テキストのコピー）と読みこみ（まるごと置きかえ）
- 暗証番号の変更
- **こくご（漢字）の出題データの表**：学年をえらび、配当漢字・ことば・よみ・送り仮名を確認・直す・行の追加／削除・さがす
  - 送り仮名が空の行 → 「よみ」「かんじえらび」に出る。送り仮名のある行 → 「おくりがな」に出る
  - 保存のときに チェック（よみは ひらがな、送り仮名は ことばと よみの 最後と同じ、同じことばの重複なし）。だめな行は 赤くなり、保存されません
  - 「最初のデータに戻す」で いつでも元どおり。編集したデータは バックアップにも入る

## ファイル
- `src/config.js` … 学年、絵、テンポ、問題数、ポイント、帽子の色と値段。**調整はほぼここ**
  - 走る速さは `RUN`（kinder / kuku / kana / kanji）：`speed`（速さ）、`gap`（門と門の間かく）、`first`（さいしょの門まで）。考える時間 ＝ gap ÷ speed 秒
- `src/run3d.js` … 選択ラン（走る画面・門・答えの判定の見た目）
- `src/storage.js` … 保存（人ごとに完全に別のキー）・バックアップ
- `src/quiz.js` … 問題と選択肢（算数・国語）
- `src/kokugo-data.js` … ひらがな・カタカナ・形のにた文字、漢字の最初のデータ（`学年|配当漢字|ことば|よみ|送り仮名` の1行1語）
- `src/sound.js` … 効果音（ファイルなし）と読み上げ
- `src/norun3d.js` … 応援ののるん
- `src/main.js` … 画面と学習の流れ（記録・復習・ポイント）

## 動作確認用
URL の末尾に `?debug` を付けると、開発者ツールから `G` で中身を操作できます。
