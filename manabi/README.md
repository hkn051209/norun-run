# のるん まなび（算数・国語の選択ラン ＋ 遊びモード）

のるんランとは別のアプリです。保存のキーも別（`norunmanabi.v1.〜`）なので、同じサイトに置いても のるんラン のデータとはまざりません。

## 公開のしかた
このフォルダの中身を、のるんランとは別のリポジトリ（または別のフォルダ。例：`/manabi/`）に置き、index.html を開くだけで遊べます。外部サイトは使いません。

## はじめての準備（保護者）
1. タイトル画面の右下「おうちのかたへ（ながおし）」を 2秒 長押し
2. 4けたの暗証番号を決める（2回入力）
3. 保護者画面で、名前・学年・アイコンを選んで「追加する」（3人ぶん。あとから追加も可）
4. お子さまが自分の名前を押すと、さいしょに「すきな絵を3つ」えらんで合言葉を決めます（2回えらんで確認）

## 遊び方（子ども）
- 名前を押す → 合言葉の絵を3つ（じゅんばんは関係なし）→ マイページ
- 年長・小1：「たしざん」→ 5まで（20問正解で 10まで が開く）。問題は自動で読み上げ。🔊でもう一度
- 小2〜小6：「くく」→ 段をえらんで じゅんばん／ランダムで9問
- 📖「こくご」（10問）
  - 年長・小1：🔊ひらがな（読み上げを聞いて、その文字の門へ）／🦊カタカナ（カタカナを見て、読みのひらがなの門へ）
  - 小2〜小6：その学年の漢字。🔤よみ／🈴かんじえらび（読みから漢字）／✍️おくりがな／🎲ミックス
  - 「📚 ならった ところまで」：教科書の はじめから どの漢字までを 出すか えらべる（その子ごとに 保存）
  - 最初のデータは 小4・小5 の分だけ（ことばは 配当漢字1字につき2語＝小4 404語・小5 386語、送り仮名は 各64語）。ほかの学年は「じゅんびちゅう」。保護者画面で その学年の ことばを3つ以上入れると遊べる
  - まちがいの選択肢は、同じ学年の ほかのことば（同じ読みのことば＝機械／機会 などは 入れない）。おくりがなは 1字へらす・ふやす形
- 学習は「選択ラン」：のるんが自動で走りつづけ、問題ごとに 答えの門が3つ（3レーン）あらわれる
  - 画面の下の 大きな ◀ ▶ ボタンで 1レーンずつ移る。左右のスワイプでも移れる（パソコンは ← → キー）
  - 門をくぐると ⭕／❌。まちがえた時は 正解の門が のるんの前で 0.55秒 みどりに光る。のるんは止まらない
  - 障害物・ジャンプはなし（遊びのラン専用）
  - 年長・小1は 門の上の看板と 画面の上に ドットで問題。読み上げも そのまま
- 🎮「あそぶ」（問題なし。記録は その子の マイページに のこる）
  - 🏃 ラン：のるんランと同じ 3レーン・障害物・ジャンプ。ぶつかるまで エンドレス（だんだん速く、障害物の ならびも むずかしく）。きょり（m）と じこベスト
    - ひくい丸太・きりかぶ → ジャンプで こえる ／ 岩・大きな木 → よける
    - はじめの速さは 保護者画面の「ランの はじめの速さ」で ゆっくり 11／ふつう 13.5／はやい 16 から えらべる（数値は config.js の RUN_SPEEDS）。アイテムなしで じゅうぶん速い
    - アイテム（config.js の RUN_ITEMS）
      - ✨ キラキラ：通れる レーンに 1列、または ひくい障害物の 上に 山なりに（ジャンプで とる）。あつめた数を 記録（バッジには ならない）
      - ⭐ ながれぼし（ボーナス）：4秒 むてき（障害物が はじけとぶ）＋ まわりの キラキラを すいよせる。速さは ほんの少し（×1.1）
      - 🫧 シャボン：1回だけ ぶつかっても だいじょうぶ
  - 🗼 とう（タワーアスレ）：コースの部品を 自動で 上へ つないで のぼりつづける。頂上なし。高さ（m）と じこベスト
    - 移動は 左下の まるい バーチャルパッド。たおした 方向にだけ 歩き、はなすと 止まる（後ろにも 歩ける）。ジャンプは 右下の ボタン
    - 部品：かいだん／すき間ジャンプ／高い段（2m〜）／ジャンプ台＋高いかべ（4m〜）／1本道が ずれる（8m〜）／動く足場（12m〜）／回るバー（16m〜）
    - 部品の あいだに チェックポイントの 旗。落ちたら すぐ 直前の旗から（何回でも OK・記録は へらない）。回るバーに 当たっても 少し もどるだけ
    - おわるのは ✕ を おした時。そこまでの いちばん高い所が 記録になる
  - ランの 操作：下の ◀ ▶（1列ずつ）＋ まんなかの ジャンプ。画面タップ・上スワイプでも ジャンプ、左右スワイプで 移動（パソコンは ← → と スペース）
  - とうの 操作：バーチャルパッド＋ジャンプボタン（パソコンは 矢印キー／WASD と スペース）
- 🎵 音：BGM（まなび／ラン／とう で 曲が かわる・ループ）と 効果音。assets/audio/ に 決まった名前の mp3 を おくと 差しかわる。保護者画面で BGM・効果音を べつべつに オン・オフ。くわしくは AUDIO.md
- 🏅 バッジ（決まり：ごほうびは 勉強でのみ。遊びの ラン・塔は 記録だけで バッジは 出ない）
  - 記録バッジ：せいかい 50／200／500、10れんぞく、ふくしゅう 10、くく ぜんぶ、こくご 100。マイページに ならぶ
- 👒 きせかえ：帽子の色（ポイントと こうかん）と、帽子の バッジ（3こまで）
  - バッジは 6種（パンダ＝はじめから／ほし＝せいかい50／ハート＝ふくしゅうで10こ やっつける／あしあと＝せいかい あわせて200／つき＝せいかい あわせて500／さかな＝こくごの せいかい100）。条件は config.js の PINS
  - つけた組み合わせは 子どもごとに 保存。メニュー・学習ラン・遊びの のるん すべてに 出る。条件を みたさなくなった バッジは 自動で はずれる
- まちがえた問題は「ふくしゅう」に たまり、2回つづけて正解すると「やっつけた！」でリストから外れる
- 九九は 3回つづけて正解すると「おぼえた」。マイページの81マスの表が埋まっていく
- 正解で ポイント（1問1ポイント、5れんぞくごとに +3）。「ぼうし」で帽子の色と交換

## 保護者画面でできること
- 学年の変更、データを消す、合言葉のリセット（子どもの画面からはできません）
- 各自の正解数・おぼえた九九の数・復習の数・ポイント・ラン／とうの じこベストの確認
- バックアップの書き出し（ファイル／テキストのコピー）と読みこみ（まるごと置きかえ）
- 暗証番号の変更
- **こくご（漢字）の出題データの表**：学年をえらび、配当漢字・ことば・よみ・送り仮名を確認・直す・行の追加／削除・さがす
  - 送り仮名が空の行 → 「よみ」「かんじえらび」に出る。送り仮名のある行 → 「おくりがな」に出る
  - 保存のときに チェック（よみは ひらがな、送り仮名は ことばと よみの 最後と同じ、同じことばの重複なし）。だめな行は 赤くなり、保存されません
  - 「最初のデータに戻す」で いつでも元どおり。編集したデータは バックアップにも入る

## ファイル
- `src/config.js` … 学年、絵、テンポ、問題数、ポイント、帽子の色と値段。**調整はほぼここ**
  - 走る速さは `RUN`（kinder / kuku / kana / kanji）：`speed`（速さ）、`gap`（門と門の間かく）、`first`（さいしょの門まで）。考える時間 ＝ gap ÷ speed 秒
- `src/run3d.js` … 選択ラン（走る画面・門・答えの判定の見た目）と、遊びのラン（障害物・ジャンプ）
- `src/tower3d.js` … 遊びの塔（タワーアスレ：コースの部品・チェックポイント・高さ）
- `src/norun-model.js` … のるんの モデル（norun-v7.glb）と 帽子の バッジの 切りかえ（userData.badgeId で 判定）
  - 速さ・むずかしさは `config.js` の `PLAY_RUN`（速さ・障害物の ならびと 出はじめる距離）と `PLAY_TOWER`（前へ進む速さ・ジャンプ・部品と 出はじめる高さ）
  - バッジの種類と条件は `config.js` の `BADGES`
- `src/storage.js` … 保存（人ごとに完全に別のキー）・バックアップ
- `src/quiz.js` … 問題と選択肢（算数・国語）
- `src/kokugo-data.js` … 漢字は 光村図書『国語』令和6年度版で 出てくる順に ならべてある。ひらがな・カタカナ・形のにた文字、漢字の最初のデータ（`学年|配当漢字|ことば|よみ|送り仮名` の1行1語）
- `src/sound.js` … 効果音（ファイルなし）と読み上げ
- `src/norun3d.js` … 応援ののるん
- `src/main.js` … 画面と学習の流れ（記録・復習・ポイント）

## 動作確認用
URL の末尾に `?debug` を付けると、開発者ツールから `G` で中身を操作できます。
