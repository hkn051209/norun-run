# デジタル シールちょう（v6）

子供のAndroidタブレットで遊ぶ、デジタルシール帳のPWAです。
サーバーやログインは不要です。データはタブレットの中（localStorage）に自動で保存されます。
外部CDNや外部フォントは使っていません。初回に読み込んだあとは、オフラインでも遊べます。

v6で変わったこと：
- **貼り方**：ドラッグで貼るのが基本になりました。タップで貼る方法も残しています。
- **ご褒美シール**：保護者があげられる、特別なシールを追加しました。
- **画像素材**：シール・机・表紙・ページ・シート台紙は、画像素材が主役の作りです。素材が無い場所だけ、仮の絵やCSSの見た目で代わりに表示します。

## ファイル構成

```
index.html                 画面のもと
css/style.css              見た目（机、バインダー、シールの質感、アニメーション）
js/data.js                 ページ（7ページ）・表紙・ご褒美の理由・遊ぶ人の設定
js/assets.js               画像の準備（シールPNGの読み込み、ダイカットのフチ作り、素材画像の読み込み）
js/sound.js                効果音（WebAudioでその場で作る。音声ファイルなし）
js/app.js                  アプリ本体
stickers/stickers.json     シールの一覧（画像ファイル・名前・シート・質感）
stickers/norun/set1/ set2/ のるんシール 64枚（norun-stickers-64.zip の画像をそのまま。加工なし）
stickers/animal/ food/ sky/ toy/ reward/   本番PNGの置き場所（いまは空。README.txt にファイル名一覧）
assets/textures/           机・表紙・ページ・シート台紙の画像の置き場所（いまは空。README.txt あり）
manifest.json, sw.js, icons/   PWA用
README.md                  このファイル
NOTES.md                   納品メモ（疑問点と、仮に決めたこと）
```

## シール画像（透過PNG）の置き方

シール1枚ごとに、`stickers/stickers.json` に次のデータを持たせています。

| 項目 | 意味 | 例 |
|---|---|---|
| `file` | 画像ファイルの場所（`stickers/` から数えた場所） | `animal/01_dog.png` |
| `name` | 名前 | `いぬ` |
| シート | どのシートの中に書いてあるか（`reward: true` のシートは、ご褒美シート） | `どうぶつ` |
| `tex` | 質感：`normal`（ふつう）、`puffy`（ぷっくり）、`water`（ウォーター） | `normal` |
| `placeholder` | 画像が無い間だけ使う、仮の絵文字 | `🐶` |

**差し替えるときは、決まった場所に、決まったファイル名でPNGを置くだけです。**

- **置き場所**：`stickers/（シート名）/` です。

  | シート名 | 中身 |
  |---|---|
  | `animal` | どうぶつ |
  | `food` | たべもの |
  | `sky` | ほし・てんき |
  | `toy` | のりもの・おもちゃ |
  | `reward` | ご褒美 |

- **ファイル名**：`番号2けた_英語名.png` です（例：`animal/01_dog.png`、`reward/02_trophy.png`）。全部の一覧は、各フォルダの `README.txt` と `stickers/stickers.json` にあります。
- **画像の形式**：透過PNGの正方形で、180×180 以上をすすめます（大きい画像は自動で縮めます）。
  - 絵の周りに少し透明な余白があると、フチがきれいに付きます。
  - 白いフチ（ご褒美シールは金色のフチ）、影、ツヤは、アプリが自動で付けます。画像そのものには付けないでください。
- **仮置きの表示**：画像が無いシールは、仮の絵文字に「かり」という札を付けて表示します。
  - いま本番PNGがあるのは、のるんの64枚です。ほかの58枚（ご褒美10枚を含む）は仮置きです。
  - 枚数は、保護者モードの「シールの え」で確認できます。
- **シールを増やすとき**：`stickers/stickers.json` に1行足します。`id` は、他と重ならない名前にしてください。
- **シールの番号**：保存データに使っているので、変えないでください。

## 机・表紙・ページ・シート台紙の画像の置き方

`assets/textures/` に、次の名前で置くと自動で使われます。画像が無い場所だけ、CSSの見た目で代わりに表示します。

| ファイル名 | 使われる場所 | 推奨サイズ |
|---|---|---|
| `desk.jpg` | 机（画面いっぱい） | 2048×1536 以上（横長） |
| `paper.png` | ページの紙の質感（繰り返して、うすく重ねる） | 512×512（端がつながる柄） |
| `cover-pink.jpg` `cover-blue.jpg` `cover-choco.jpg` `cover-star.jpg` | 表紙4種類の、透明カバーの下に見える絵 | 1000×1300 |
| `page-sora.jpg` `page-umi.jpg` `page-mori.jpg` `page-okashi.jpg` `page-uchu.jpg` `page-hana.jpg` | 1〜6ページの背景 | 900×1200（縦3：横4） |
| `page-gohoubi.jpg` | 7ページ目（ご褒美ページ）の背景 | 900×1200 |
| `sheet-animal.jpg` `sheet-food.jpg` `sheet-sky.jpg` `sheet-toy.jpg` `sheet-reward.jpg` | シールシートの台紙 | 1600×1000（横長） |
| `sheet-norun1.jpg` `sheet-norun2.jpg` | のるんシートの台紙（シールが多いので縦長め） | 1600×1600 |

画像を置いても、次のものはその上に重ねて表示します。
- 透明カバーの反射
- リングの金属の光沢
- 留め具ベルト
- 帳面の影
- 台紙のレースの縁

## 貼り方

- **ドラッグ（基本）**
  - 右（縦向きのときは下）の「はる シール」のシールに指を置いて、ページまで動かして離すと、その場所に貼れます。
  - ドラッグ中は、シールが指に付いて少し大きくなり、影が付きます。貼れる場所の上では、シールとページが光ります。
  - 「もちもの」画面からドラッグしても、シール帳が開いてそのまま貼れます。
  - 指を少し押さえてから動かすか、横に動かすとつかめます。縦向きのときは上に動かします。トレイをスクロールしたいときは、トレイが並んでいる向きに動かしてください。
- **タップ（補助）**：シールをタップして選び、ページの貼りたい場所をタップします。
- **貼ったシールを動かす**：指でドラッグします。タップすると「おおきく／ちいさく／まわす／はがす」のボタンが出ます。
- **はがす**：帳面の外や「はる シール」の所までドラッグして離すと、はがれて持ち物に戻ります。

## ご褒美シール

- **あげ方（保護者モードの一番上）**
  1. 上のタブで子供を選びます。
  2. ご褒美シールを選びます。
  3. 理由を選びます。理由は絵と色のボタンで、「おてつだい」「がんばった」「テスト」「おかたづけ」「おやくそくを まもった」「そのほか」です。
  4. 「あげる」を押します。
- **受け取り**
  - 子供が次にそのデータを開いたとき、お祝いの演出が出ます。光、紙ふぶき、ファンファーレと一緒に、大きく表示されます。
  - 「やったー！」を押すと、持ち物に入ります。
  - 保護者モードを閉じたとき、今開いているデータにご褒美があれば、その場で受け取り演出が出ます。
- **入手方法**：ご褒美シールは、普通のシートやガチャでは手に入りません。ご褒美シートは見るだけです。
- **見た目**：ご褒美シールは普通より少し大きく、金色のフチ、光の筋、キラキラが付きます。
- **ご褒美ページ（7ページ目）**
  - 「🏆 ならべる」では、もらった順に、日付と理由付きで並びます。
  - 「✋ はる」では、ご褒美シールだけを自由に貼れます。
  - ご褒美シールは、ほかのページにも貼れます。
- **履歴**：保護者モードの「ごほうびの りれき」で、全データ分が見られます。いつ、だれに、どのシールを、どの理由であげたかと、届いたかどうかが分かります。

## GitHub Pagesに置く手順

1. GitHubで新しいリポジトリを作ります（例：`sealbook`）。公開（Public）にします。
2. このZIPを展開してできる `seal-book` フォルダの**中身**を全部、リポジトリの一番上に置きます。
   - ブラウザで置く場合は、「Add file」から「Upload files」を選び、中身をまとめてドラッグして「Commit changes」を押します。
3. 「Settings」から「Pages」を開きます。
4. 「Source」で「Deploy from a branch」を選び、Branchは `main`、フォルダは `/ (root)` にして「Save」を押します。
5. 1〜2分で `https://（ユーザー名）.github.io/sealbook/` に公開されます。

パスはすべて相対パスなので、リポジトリ名は何でも動きます。

## タブレットにインストールする手順（Android／Chrome）

1. タブレットのChromeで、上のURLを開きます。
2. 「シールを じゅんびちゅう…」のあと、だれが遊ぶかを選ぶ画面が出ます。そのまま1分ほど待つと、オフライン用のファイルが保存されます。
3. Chromeの右上の「︙」メニューから「ホーム画面に追加」または「アプリをインストール」を選び、「インストール」を押します。
4. ホーム画面の「シールちょう」アイコンから開けます。
5. 確認のため、機内モードにして開き、のるんシートが表示されればOKです。

注意：Chromeの「サイトデータを削除」や、アプリのアンインストールをすると、データも消えます。

## 保護者モード

- 🔒 ボタンから、4桁のパスワードを入れて開きます。**初期値は 1234** です。
- できること：
  - ご褒美シールをあげる（一番上）
  - ガチャ券をあげる（+1／+5）
  - 好きなシールをあげる（全シートから選べ、質感も選べます。ご褒美シートは、ご褒美の欄からあげます）
  - 名前と顔マークの変更
  - データのリセット（確認が2回出ます）
  - パスワードの変更
  - シールの絵の確認（本番PNGと仮置きの枚数）
  - ご褒美の履歴を見る

## 更新するとき

ファイルを直したり、PNGを上書きしたり、`stickers.json` を書き換えたりしたら、`sw.js` の `CACHE` の名前を変えてください（例：`sealbook-v6-1` → `sealbook-v6-2`）。名前を変えると、タブレット側の古いファイルが入れ替わります。

仮置きだったシールのPNGや、まだ無かった質感画像を新しく置いただけなら、`CACHE` を変えなくても大丈夫です。最初にネットにつないで開いたときに、自動で保存されます。

シール帳のデータは消えません。v4・v5のデータもそのまま使えます。
