# デジタル シールちょう（v5）

子供のAndroidタブレットで遊ぶ、デジタルシール帳のPWAです。
サーバーやログインは不要です。データはタブレットの中（localStorage）に自動で保存されます。
外部CDNや外部フォントは使っていません。初回に読み込んだあとは、オフラインでも遊べます。

v5では、シールを画像（透過PNG）が主役の作りに変えました。フチ・影・ツヤ・ドームは、画像の上に重ねる演出です。
帳面も、リアル寄りの見た目にしました。

## ファイル構成

```
index.html                 画面のもと
css/style.css              見た目（机、バインダー、シールの質感、アニメーション）
js/data.js                 ページ・表紙・遊ぶ人の設定
js/assets.js               画像の準備（シールPNGの読み込み、ダイカットのフチ作り、質感画像の読み込み）
js/sound.js                効果音（WebAudioでその場で作る。音声ファイルなし）
js/app.js                  アプリ本体
stickers/stickers.json     シールの一覧（画像ファイル・名前・シート・質感）
stickers/norun/set1/       のるんシール 32枚（norun-stickers-64.zip の画像をそのまま。加工なし）
stickers/norun/set2/       のるんシール 32枚（同上）
stickers/animal/ food/ sky/ toy/   本番PNGの置き場所（いまは空。README.txt にファイル名一覧）
assets/textures/           机・表紙・ページの質感画像の置き場所（いまは空。README.txt あり）
manifest.json, sw.js, icons/       PWA用
README.md                  このファイル
NOTES.md                   納品メモ（疑問点と、仮に決めたこと）
```

## シール画像（透過PNG）の置き方

シール1枚ごとに、`stickers/stickers.json` に次の4つを持たせています。

| 項目 | 意味 | 例 |
|---|---|---|
| `file` | 画像ファイルの場所（`stickers/` から） | `animal/01_dog.png` |
| `name` | 名前（ひらがな・カタカナ） | `いぬ` |
| シート | どのシートの中に書いてあるか | `どうぶつ` |
| `tex` | 質感：`normal`（ふつう）／`puffy`（ぷっくり）／`water`（ウォーター） | `normal` |

ほかに、`placeholder`（画像が無いときだけ使う仮の絵文字）を持っています。

**画像を差し替えるには、決まった場所に、決まったファイル名でPNGを置くだけです。** ほかに直す所はありません。

- 置き場所：`stickers/（シート名）/` の中です。シート名は `animal`（どうぶつ）、`food`（たべもの）、`sky`（ほし・てんき）、`toy`（のりもの・おもちゃ）です。
- ファイル名：`番号2けた_英語名.png` です（例：`animal/01_dog.png`、`food/04_softcream.png`）。全部の一覧は、各フォルダの `README.txt` と `stickers/stickers.json` にあります。
- 画像の形式：
  - 透過PNGの正方形で、180×180 以上をすすめます。180×180 より大きい画像は、自動で縮めて表示します。
  - 絵の周りに少し透明な余白があると、白いフチがきれいに付きます。
  - 白いフチ・影・ツヤは、アプリが自動で付けます。画像そのものには付けないでください。
- ファイルが無いシールは、仮の絵文字で表示されます。いま本番PNGがあるのは、のるんシール64枚です。ほかの48枚は仮の絵文字です。今の枚数は、保護者モードの「シールの え」で確認できます。
- 後から別のZIPで素材をもらったら、中のPNGを上のルールで置いて、GitHubに上げてください。
- 新しいシールを増やすときは、`stickers/stickers.json` の該当シートに1行足します。`id` は他と重ならない名前にしてください。
- 質感を変えたいときは、`tex` を書き換えます。
- 同じ名前のファイルを上書きしたときは、`sw.js` の `CACHE` の名前を変えてください（下の「更新するとき」を見てください）。

## 机・表紙・ページの質感画像の置き方

`assets/textures/` に、次の名前で画像を置くと、自動で使われます。置かなければ、CSSで作った見た目のままです。

| ファイル名 | 使われる場所 |
|---|---|
| `desk.jpg` | 机（画面いっぱい） |
| `paper.png` | ページの紙の質感（繰り返して、うすく重ねる） |
| `cover-pink.jpg` `cover-blue.jpg` `cover-choco.jpg` `cover-star.jpg` | 表紙4種類の中の絵（透明カバーの下に見える） |
| `page-sora.jpg` `page-umi.jpg` `page-mori.jpg` `page-okashi.jpg` `page-uchu.jpg` `page-hana.jpg` | 6ページの背景（縦3：横4。例 900×1200） |

透明カバーの反射、リングの金属の光沢、ベルト、影は、画像を置いても上に重ねて表示します。

## GitHub Pagesに置く手順

1. GitHubで新しいリポジトリを作ります（例：`sealbook`）。公開（Public）にします。
2. このZIPを展開すると `seal-book` フォルダができます。その**中身**（ファイルとフォルダ全部）を、リポジトリの一番上に置きます。
   - ブラウザで置く場合は、リポジトリの「Add file」から「Upload files」を選び、展開したフォルダの中身をまとめてドラッグして「Commit changes」を押します。
3. リポジトリの「Settings」から「Pages」を開きます。
4. 「Build and deployment」の「Source」で「Deploy from a branch」を選びます。Branchは `main`、フォルダは `/ (root)` にして「Save」を押します。
5. 1〜2分待つと、`https://（ユーザー名）.github.io/sealbook/` で公開されます。

パスはすべて相対パスなので、リポジトリ名は何でも動きます。

## タブレットにインストールする手順（Android／Chrome）

1. タブレットのChromeで、上のURLを開きます。
2. 「シールを じゅんびちゅう…」のあと、だれが遊ぶかを選ぶ画面が出ます。そのまま1分ほど待ちます。この間に、オフライン用のファイルが保存されます。
3. Chromeの右上の「︙」メニューから「ホーム画面に追加」または「アプリをインストール」を選び、「インストール」を押します。
4. ホーム画面に「シールちょう」のアイコンが出ます。次からはそこから開けます。
5. 確認のため、機内モードにしてアイコンから開き、のるんシートが表示されればOKです。

注意：Chromeの「サイトデータを削除」や、アプリのアンインストールをすると、シール帳のデータも消えます。

## 使い方（かんたん）

- 最初の画面で、遊ぶ人（4人分）を選びます。
- 📖 **シールちょう**：
  - 「ひらく」を押すと、ベルトが外れて表紙が開きます。「ちょうを えらぶ」で、表紙を4種類から選べます。
  - 「はる シール」でシールを選び、ページをタップすると貼れます。
  - 貼ったシールは指でドラッグして動かせます。タップすると「おおきく／ちいさく／まわす／はがす」のボタンが出ます。
  - ページは「まえ／つぎ」ボタンか、指のスワイプでめくれます。
- 🎒 **もちもの**：持っているシールと数の一覧です。
- 📄 **シールシート**：6シートあります。シールをタップすると、もちものに1個入ります。
- 🎰 **ガチャ**：ガチャ券1枚で1回まわせます。券は保護者モードであげます。
- 🔄 **こうかん**：ほかのデータとの交換と、プレゼントができます。履歴も残ります。
- 🔊 ボタンで音のオン・オフ、🔒 ボタンで保護者モードです。

## 保護者モード

- 🔒 ボタンを押して、4桁のパスワードを入れます。**初期値は 1234** です。
- できること：
  - ガチャ券をあげる（+1／+5）
  - 好きなシールをあげる（全シートから選べて、質感も選べます）
  - 名前と顔マークの変更
  - データのリセット（確認が2回出ます）
  - パスワードの変更
  - 本番PNGと仮の絵文字の枚数の確認

## 更新するとき

ファイルを直したり、PNGを上書きしたりしてGitHubに上げたら、`sw.js` の `CACHE` の名前を変えてください（例：`sealbook-v5-1` → `sealbook-v5-2`）。名前を変えると、タブレット側に保存してある古いファイルが入れ替わります。

`stickers/stickers.json` を書き換えたときも、`CACHE` の名前を変えてください。

**仮の絵文字だったシールのPNGを、新しく置いただけ**のときは、`CACHE` を変えなくても大丈夫です。最初にネットにつないで開いたときに、自動で保存されます。

シール帳のデータ（localStorage）は、どちらの場合も消えません。v4のデータもそのまま使えます。
